# DESIGN — Apple 发布会风格样片

> 本文件是本项目的设计宪法。逐页制作严格对照本文件；与通用法则冲突之处，以本文件的「覆盖声明」为准（依据：用户在需求中已显式锁定风格 —— 参考视频即风格规范）。

---

## 0. 覆盖声明（留白型 · 用户显式风格指令）

| 通用默认 | 本项目取值 | 依据 |
| :--- | :--- | :--- |
| 常规内容页留白 ≤ 35% | **留白 68%–82%**（封面/收尾不限） | 该风格的「空」就是内容，一屏一句话 |
| 配图系统 L1/L2/L3 | **不使用摄影/插画/3D 配图**；主视觉 = 巨型文字（≥ 96px） | 文字即画面，是该风格的定义特征 |
| 页脚条含右下页码 `NN/TOTAL` | **取消页码**；C 区只保留一枚极淡品牌字 `NOVA` | 页码会击穿「发布会现场感」 |
| 对称版式全篇 ≤ 2 页 | **仅 `01` 封面、`10` 收尾 2 页居中** | 居中留给开场与收尾，是风格语法 |
| 巨型字号上限 120px | **上限 190px** | 发布会上数字就是主角 |
| 强调色面积 ≤ 10% | **每页至多一处渐变焦点** | 渐变是本风格的签名，用「每页一处」约束其克制 |

## 1. 画布与母版

- **画布**：1280 × 720（16:9），背景恒为 `#000000`。
- **安全区（padding）**：`76px 88px`（上下 76 / 左右 88）。内容一律在安全区内用 Flex 排布，不使用绝对定位绕过。
- **母版三区（本项目重定义）**：

| 区 | 垂直位置 | 内容 | 规格 |
| :--- | :--- | :--- | :--- |
| **A · 顶标签带** | y ≈ 76–110 | 章节索引标签（`01 / THE IDEA`） | `Segoe UI` 13px，字距 3px，`#F5F5F7` @ opacity 0.42 |
| **B · 主文案区** | y ≈ 110–620 | 巨型文案块（垂直居中于本区） | 见 §3 字号阶梯 |
| **C · 底部品牌条** | y ≈ 620–644 | 品牌字 `NOVA`（全篇位置一致） | `Segoe UI` 12px，字距 4px，`#3A3A3D` |

- **排布方式**：`Slide` 设 `display:flex; flexDirection:column; justifyContent:space-between`，自然得到「标签贴顶 / 文案居中 / 品牌贴底」。封面与收尾页省略 A 区。

## 2. 颜色系统

| 角色 | 值 | 面积占比 | 用法 |
| :--- | :--- | :--- | :--- |
| 主色（背景） | `#000000` | ≥ 88% | 全片底色 |
| 文本 · 亮 | `#F5F5F7` | ≈ 6% | 当前正在讲的词、巨型文案主体 |
| 文本 · 暗 | `#3A3A3D` | ≈ 3% | 「已经讲过的词」——制造逐词点亮的降级层 |
| 强调（渐变方案 **Aurora**） | `linear-gradient(90deg, #4B8DFF 0%, #A66BFF 46%, #FF5E7A 100%)` | ≤ 3%，**每页至多一处焦点** | 封面后的高光词、巨型数字、价值词、金句落点；转场页的那条极细色带 |

- 半透明策略：A 区标签用 `#F5F5F7` + `opacity 0.42`；小注文字用 `#F5F5F7` + `opacity 0.42`。不使用除上述外的任何颜色。
- 渐变使用节奏（避免每页雷同）：`01` 无 → `03` 仅细线 → `04` 高光词 → `05` 巨型数字 → `07` 内联单字 → `08` 价值词 → `09` 金句落点；`02` `06` `10` 为纯白/灰的「留白页」，用来给渐变降噪。

## 3. 字体系统

**家族 A · `Arial`**（全部巨型文案与正文）——作为 Helvetica Neue 的落地替代：Windows 通用、字形紧凑中性，巨型字重下最接近发布会的无衬线气质。
**家族 B · `Segoe UI`**（仅标签、底部品牌字、小注）——小字号下更精致，配合字距拉开形成「脚注感」。

| 层级 | 字号 | 字重 | 行高 | 字距 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 开场巨字 | 164 | bold | 1.0 | -1 | 封面 `hello.` |
| 收尾巨字 | 104 | bold | 1.05 | -1 | `Thank you.` |
| 主文案巨字 | 96–112 | bold | 1.06 | -1 | 各页巨型落点 |
| 同块次行（暗） | 64 | bold | 1.12 | -0.5 | `Technology should feel` |
| 巨型数字 | 190 | bold | 1.0 | -2 | `40` |
| 数字单位 | 60 | bold | 1.0 | 0 | `hours` |
| 列表中项 | 72 | bold | 1.18 | -1 | `Responsible.` 等 |
| 转场巨字 | 120 | bold | 1.0 | -1 | `Introducing` |
| 章节索引标签 | 13 | regular | 1.2 | 3 | A 区 |
| 小注 / 引导句 | 20 | regular | 1.5 | 0.2 | 页面小字判断 |
| 底部品牌字 | 12 | regular | 1.2 | 4 | C 区 |

## 4. 动画策略（还原「逐词点亮」）

- **类型统一 `fadeIn`**，全篇不混用其它动画；`duration 600ms`、`delay 0`。
- 以 `startType="afterPrevious"` 串联，形成「一句话一行行长出来」的节奏；每页首个动画用 `startType="click"`。
- **每页动画 ≤ 4 个**。A 区标签、C 区品牌字**不加动画**；转场页的渐变细线跟随巨字入场。
- 已讲过的词「压暗」由 `#3A3A3D` 静态承载，动画只负责「依次点亮」，二者叠加即得到参考视频的聚焦拖尾感。

## 7. 动笔自检（每页提交前）

1. 背景为 `#000000`，仅用 §2 四色（含渐变方案）
2. 巨型文案在安全区内，总高 ≤ 720 − 76×2 = 568
3. 本页有且仅有一个 ≥ 96px 的视觉锚点（巨型文案/数字本身）
4. 渐变至多出现一处焦点；`02` `06` `10` 页不使用渐变
5. 与上一页版式不重复；相邻页锚定方向（左/中）不同
6. 字号阶梯取自 §3，不临时发明新字号
7. 动画 ≤ 4 个，全为 `fadeIn`，标签/品牌字无动画
8. 留白落在 §0 声明的 68%–82% 区间，且留白围绕焦点元素
9. 文案与 §6 逐字一致
10. A 区标签（如有）与 C 区品牌字位置与其它页严格对齐
