# STORY — Apple 发布会风格样片

## ① 用户意图对齐

- **目标受众**：把这版当作「高级感风格样板」来评估的人（团队内部 / 客户提案场景）。内容为演示用样例，后续可整体替换为真实业务的文案。
- **核心目标**：让观众在第一页就认出这是「发布会」的语言——相信这套视觉可以直接上正式场合；记住三件事：纯黑舞台、巨型字、渐变高光。
- **PPT 长度**：10 页。Hero 页 3 页（30%）。
- **视觉调性**：发布会式 · 极简克制 · 电影感 · 零装饰 · 大留白。
- **内容边界**：
  - 必讲：逐词点亮（已讲过的词压暗）、巨型数字锚点、渐变高光词、价值列表、收尾金句。
  - 不讲：数据图表、摄影配图、目录页、页脚页码——这些都会破坏「一屏一句话」的连贯幻觉。
  - 禁碰：任何装饰性小图形、卡片容器、边框。

## ② 页面布局骨架

- **页面总数与分章**：10 页，**无目录页、无章节扉页**——该风格用连续大字流替代分章，因此显式取消「目录 ↔ 章节扉页」契约（未声明目录，即不触发该契约）。
- **Hero 页定位**：`01 封面` / `04 产品揭幕` / `10 收尾`，共 3 页（30%），互不相邻（1→4 之间隔 2 页，4→10 之间隔 5 页）。
- **rhythm 曲线**：
  `01 peak → 02 valley → 03 transition → 04 peak → 05 valley → 06 peak → 07 valley → 08 peak → 09 peak → 10 peak`
  无连续 ≥ 3 页 valley。
- **非对称版式预算**：8 页（80%）采用非对称构图；仅 `01`、`10` 两页为居中对称（满足「对称版式全篇 ≤ 2 页」）。作为覆盖声明：本风格的构图以「文字锚定在画面左/下侧」为主，居中仅留给开场与收尾，这是风格本身的语法，而非偷懒。
- **版式序列（相邻页版式均不同）**：
  居中巨字 → 左上标签+左巨字 → 左巨字+渐变细线 → 左巨字+渐变词 → 巨型数字左锚 → 小引子+巨字收束 → 左巨字+内联渐变词 → 标签+列表 → 顶部小词+左巨字 → 居中巨字。
