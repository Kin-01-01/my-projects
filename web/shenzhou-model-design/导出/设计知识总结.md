## 1. 系统架构与数据流

```

   │
   ├─ launch.js  发射栈建模 + 上升物理 + 分离动力学 + 火焰着色器 + 粒子系统

**渲染管线**：`Scene → RenderPass → UnrealBloomPass → OutputPass`（`main.js:85-90`）。

**快进**：`seek(tt)` 调 `reset()` 后以 `1/60` 固定步长快进到目标（`launch.js:2513`），保证分离积分状态正确。

mission = lerp(mission[i-1], mission[i], k)     alt / vel 同理
```

## 3. 上升段物理模型（launch.js:42-80）

### 3.1 推力爬升

```
u = min(1, (t - T_IGN) / SIM.ramp)          ramp = u²(3 - 2u)   [smoothstep]
a_thrust(t) = SIM.twr · g · ramp            twr = 1.3, g = 9.81, ramp = 4.4 s
```

### 3.2 燃料消耗（质量下降 → 推重比增大）

```
massFrac(t) = 1 - burnFrac · min(1, (t-T_IGN)/SIM_BURN)     burnFrac = 0.8
weightAcc(t) = g · massFrac
```

### 3.3 发射台锁死判据（真实"约 3 秒多才离塔"）

```
若未解锁： 释放 ⟺ a_thrust(t) > weightAcc(t)      （或面板指定 LIFT 时刻）
```

数值解：`1.3g·smoothstep(t/4.4) > g·massFrac` → **t ≈ 3.05 s** 解锁离塔，与总设计师口径一致。
解锁前 `a=0`、位置不变（压紧机构锁死）。

### 3.4 解锁后积分（半隐式欧拉）

```
a = a_thrust / massFrac - g
v ← v + a·dt ;  h ← h + v·dt
```

### 3.5 视觉高度压缩（有界、避免相机被真实米数撑爆）

```
sceneY = SCENE_ALT_MAX · (1 - exp(-simAltM / SIM_H0))
SCENE_ALT_MAX = 900, SIM_H0 = 3500
```

低空近线性（爬升可见），高空饱和到 900。

### 3.6 程序转弯（重力转向）

```
tTurn = T_IGN + PITCH_T0 (=27)      PITCH_T0 = 17
θ(t) = PITCH_MAX · smoothstep( (t - tTurn) / PITCH_SPAN )     PITCH_MAX = 62°, PITCH_SPAN = 206.5 s
dX = tan(θ) · dY（横向随倾角积分）；箭体 rotation.z = -θ（机头沿弹道切线）
```

`PITCH_T0=17` 保证起转时箭体已高过 62 m 塔顶（安全余量 ≈19 m）。

## 4. 分离刚体动力学（launch.js:2215-2280）

### 4.1 逐帧积分

软启动/软停止的分离推力窗（避免速度跳变）：

```
burn(te) = smoothstep(0, 0.14, te) · (1 - smoothstep(SEP_BURN-0.14, SEP_BURN, te))    SEP_BURN = 0.5 s
a_sep = dir · sepAcc · burn
a_y  = dir_y·sepAcc·burn - (g + a_rocket)      ← 重力 + 火箭向上加速带来的【惯性力】
v   += a·dt - v·DRAG_LINEAR·dt                  DRAG_LINEAR = 0.30
ω   *= (1 - DRAG_ANGULAR·dt)                    DRAG_ANGULAR = 0.22
p   += v·dt
```

`a_rocket` 用第 3 节的真实净加速度（而非旧的解析常数，后者在 116 s 时给出 143 m/s²，会把分离体甩出几公里）。

各分离体参数：`sepAcc` 逃逸塔 16 / 助推器 8 / 芯一级 3.6 / 上面级 2.4；翻滚 `wz` 0.8 / — / 0.55 / 0.2。

### 4.2 约束求解（从根源杜绝穿模）

1. **径向安全轴距**：`target = radial0 + (safeRadial - radial0)·smoothstep(0, SEP_BURN·1.8, te)`，
   取 `max(当前, target, 历史最小)`；外推时**清除指向轴心的速度分量**。
2. **轴向让开**（芯级/上级向下分离）：间隙量**单调不减**（`maxAxial`），不允许回弹。
3. **地面**：底部不低于 `GROUND_MIN = 1.0 m`，并清零向下速度。

单调量（`minRadial / maxAxial`）是本设计的关键：**分离间隙只增不减**，杜绝回弹穿模。

### 4.3 淡出

`te > 8 s` 起缩小、`te > 14 s` 隐藏（坠落过程可见时间更长）。

## 5. 火焰着色器数学模型（launch.js:1433-1555）

所有焰层共用一套 ShaderMaterial 源（程序共享，uniform 各异）。

### 5.1 顶点：湍流位移 + 呼吸

```
w = v² · uTurb                       v = vUv.y（0 喷口端 → 1 远端）
p.x += (sin(p.y·1.7 + t·13)·0.16 + sin(p.y·3.9 - t·21)·0.07)·w
p.z += (cos(p.y·1.3 + t·11)·0.16 + sin(p.y·3.1 + t·17)·0.07)·w
vPulse = 0.86 + 0.14·sin(v·7 - t·6)
```

`uTurb` 按几何尺度缩小（小羽流减弱），否则绝对位移会把细焰撕碎。

### 5.2 片元：alpha 链式乘积

```
nz   = |normalize(vNrmV).z|
fres = (1 - nz)^1.25                      1 = 轮廓掠射, 0 = 正对镜头
body = mix(1, uHollow, fres)              【体积感】中心厚、轮廓薄
v    = mix(vUv.y, 1 - vUv.y, uFlipEnd)    统一"离喷口的距离"
ends = mix(uRoot, uTip, smoothstep(0.45, 1, v))    双端渐隐
clump= 0.60 + 0.78·(0.66·noise1 + 0.34·noise2)     值噪声气团
clump= mix(1, clump, uPatch·clamp(0.30 + 0.95·v, 0, 1))  越靠远端越斑驳
tear = 0.88 + 0.12·sin(u·18.85 + v·9 + t·23)
dia  = 1 + uDiamond·sin(v·42 - t·3)       【马赫环】超声速激波菱形
a    = uOpacity·uFlicker·body·ends·clump·tear·vPulse·max(dia, 0.15)
if (a < 0.004) discard;                   加色混合输出
```

**加色混合预算（重要经验）**：最终 alpha 是 6~7 个因子的**连乘**，每项 ≈0.5~0.9 会把名义值削掉 3~4 倍。
写 `uOpacity=0.5` 实际只有 ≈0.08，在黑底上几乎不可见 → 调参时必须按"有效 alpha ≈ 名义值 × 0.3"估算。

### 5.3 关键修正（体积感方向）

旧实现 `edge = 0.42 + 0.78·fres`（**轮廓更亮**）→ 焰锥看着像一圈发光的**空心几何壳**、边缘硬直线。
现 `body = mix(1, uHollow, fres)`（**中心厚、轮廓薄**）→ 真实的充实发光气柱。

### 5.4 羽流随高度膨胀

```
plume = 1 + min(sceneY / 250, 3)                  一级/助推器：sx, sy ∝ plume
二级（真空，长而散）：sxU ∝ 1 + (plume-1)·0.40，syU ∝ 1 + (plume-1)·0.95
```

径向增幅被刻意克制（否则 2.25 m 直径的二级会顶出一个又粗又硬的大锥）。

## 8. 太阳翼运动学（spacecraft.js:265-305）

三段时序（p ∈ [0,1]）：

```
① 解锁段  0~0.10   保持收拢
② 根部旋出 0.10~0.34  hinge.rotation.y = -side·(π/2)·ease(p)     右翼 0→-90°，左翼 0→+90°（镜像同步）
③ 手风琴展开 0.34~1  start_i = 0.34 + i·0.055，q = (p-start_i)/0.13
                     hinge_i.rotation.y = ±π·(1-ease(q))，符号按【该翼自己的段序号】交替
                     折叠垫层 z_i = 0.055·(i+1)·(1-ease)  → 收拢分层不共面，展开归零
ease(x) = x<0.5 ? 4x³ : 1 - (-2x+2)³/2   （easeInOutCubic）
```

层级（严格机械连接）：

```
推进舱本体 → hinge（轴心在侧壁根部 x=±1.28，旋转轴沿飞船纵向 Y）
              ├─ 安装座 → 驱动箱 → 叉形支架 → 转轴 → 根部轮毂（不悬空）
              └─ 太阳翼（段1→段2→段3→段4，逐段铰接）
```

**历史 bug**：`w.userData.hinges` 从未赋值 → 手风琴折叠根本没动，收拢时是一整条 7.2 m 刚性板被整体旋转，甩到船体下方。已改为每侧翼独立挂 `hinges`。

## 10. 音频旁白定位算法（离线、无需语音识别）

1. 10 ms 步长求 RMS 能量包络 → `loud(t)`。
2. 2 s 滑窗对包络做 DFT，算**语音调制比**：
   `mod = E(3~8 Hz) / E(0.5~12 Hz)`（人声音节包络集中在 3–8 Hz，音乐/爆响不在此带）。
3. 判据：`mod ≥ 0.30 且 loud ≥ 0.06` = 有人在播报；`loud 高但 mod < 0.20` = 纯音乐/火工品爆响。
4. 事件默认时刻 = 旁白起振点 **+ 0.9~1.7 s**（话音响起、动作紧跟）。
5. 用户端微调：面板「事件对齐」→ 听到该句瞬间点「以当前时刻对齐」，或 ±2 s 微调（持久化）。

> **经验**：音量门限曾设 10%，漏掉了音量仅 15% 的"轻声旁白"（95.0–100.2 s 正是"一二级分离"所在）。
> 放宽到 6% 后全片由 19 段增至 25 段。

## 11. 排障知识与关键坑（按代价排序）

| 坑 | 症状 | 定位/解决 |
|---|---|---|
| **GLSL 保留字 `patch`** | 火焰材质全部不渲染；控制台反复 `useProgram: program not valid` | 抓 `Runtime.consoleAPICalled`+`Log.entryAdded` 全量日志 → `ERROR: 'patch' : Illegal use of reserved word`。改名 `clump`。（GLSL 命名须避开 patch/ends/input/output…） |
| 着色器"量纲混算" | 只有主火箭喷火、助推器没火焰 | 曾把"米制半径 / 归一化高度因子"当 0~1 比较 → 底半径 >1 m 的层全被抹透明。改用视空间法线项。 |
| `uTime` 未声明 | 片元编译失败、整套火焰不渲染 | 片元里用了 `uTime` 却没写 `uniform float uTime;` |
| 羽流裙渐隐端反了 | 末端一条硬邦邦的圆形切口（用户截图里的"橙色圆盘"） | 其"宽端在远端" → 需 `uFlipEnd = 1` |
| 归一化的 alpha 预算 | 参数调大但画面没变化 | 加色混合下 6~7 项连乘，有效 alpha ≈ 名义 ×0.3 |
| 泛光扩散 | "光晕太大"且调灯无效 | `UnrealBloomPass` 的 **radius** 才是范围旋钮 |
| 探针失真 | 截图里看不到火焰 | ①`seek()` 必须配合 `L.start()` 先进入发射场景；②相机不能沿羽流轴向（会被透视压成一点），要取垂直方向；③用全新端口起服务可排除缓存 |
| 二分法定位着色器 | — | 极简着色器（纯色输出）→ 逐层加回 varyings / uniforms / 函数 / 语句体，配合"移出箭体到空域"排除遮挡 |

## 13. 一句话经验

1. **先证明"渲染了"再谈"好不好看"**（draw call ≠ 出像素；着色器编译失败时几何/材质一切正常）。
2. **物理量与视觉量的换算要显式建模**（视觉压缩、遥测映射、羽流膨胀），否则"看起来不对"无法定位。
3. **音画同步只能由"听得见的人"闭环**：提供可持久化、可清除、逐事件可校准的工具，而不是反复猜时刻。
4. **所有调参入口收敛到单一数值**，并在面板/版本行暴露当前值，避免"改了没生效"的信任危机。
