## 0. 现状与差距（先说结论）

| 维度   | 当前实现                                                         | 真实火箭                    | 影响                |
| ---- | ------------------------------------------------------------ | ----------------------- | ----------------- |
| 箭体运动 | `launch.js:1601` 解析式 `rocketY = 0.5·a₀·tₖ² + K/6·tₖ³`，只算竖直高度 | 六自由度、质量随推进剂消耗变化、重力转弯    | 轨迹是"电梯"，不是弹道      |
| 姿态   | 无（箭体旋转量恒为 0）                                                 | 滚转程序 + 程序俯仰 + 闭环修正      | 真实感缺失，且没有"姿态修正"可讲 |
| 气动力  | 无                                                            | 动压、最大动压点、马赫相关阻力         | 无法呈现"最险的一段"       |
| 分离体  | `makeSepBody` 有惯性力、重力、阻尼，无气动                                 | 受气动力明显，助推器迅速落后于主体       | 分离后像在真空里飘         |
| 表面材质 | 每种蒙皮只有一张贴图，金属度/粗糙度是单个标量                                      | 白漆半光、铆钉焊缝有起伏、局部金属裸露     | 一打光就显塑料感          |
| 喷管   | `bellProfile()` 单层回转体 + 一个圆环                                 | 再生冷却管束、涡轮排气管、摇摆作动筒、腔内碳化 | 尾段最靠近镜头却最粗糙       |
| 播报   | 3 段固定时间点 mp3 + 50 秒合成主音频                                     | 事件驱动、与飞行状态严格对应          | 跳转/暂停/音频失败即错位     |
| 时钟   | 场景时间由音频播放头驱动（`main.js:419`）                                  | 主时钟独立，音频跟随              | 倒数图文不同步属于同一根因     |

## 1. 模块 A：表面材质、接缝、喷口（建模层）

### A1 材质体系由「单贴图」升级为「贴图组」

目标：同一套程序化画布同时产出 `map / normalMap / roughnessMap`，让铆钉与焊缝在光下有真实起伏。

做法：

1. 新建 `makeSkinSet(opts)`（放在 `makeRocketSkin` 附近），先画一张灰度母版（面板缝、铆钉、焊缝、流痕），再派生三张：
   - `map`：底色 + 标识 + 母版叠加
   - `normalMap`：对母版做 Sobel 边缘运算得到法线（`THREE.DataTexture`，1024² 约 3MB，单套可接受）
   - `roughnessMap`：白漆基体约 0.42，铆钉与焊缝约 0.62，流痕带约 0.52
2. 白漆改为 `MeshPhysicalMaterial`：`metalness 0.06 / roughness 0.44 / clearcoat 0.35 / clearcoatRoughness 0.26 / envMapIntensity 0.9`
   - 真实箭体是半光白漆 + 局部镀铝薄膜与隔热毡，金属感很低；当前 `metalness 0.2~0.35` 偏高，这一步能明显减少塑料感。
3. 分轮替换，每轮都用固定机位、同一时刻截图对比，不一刀切：
   - 第 1 轮：`fairMat`（整流罩）、`upperSkinMat`（二级）
   - 第 2 轮：`coreSkinMat`（芯一级）、助推器
   - 第 3 轮：发射台与塔架（若共用材质则一并受益）

### A2 接缝与装配特征（补几何）

- 新增通用构造 `makeJointRing(r, y, boltCount)`：环形薄壁 + 轴向一圈螺栓 + 交界处"白带 / 暗线 / 白带"三明治薄环。现有 `boltBand` 只覆盖芯一级顶部，推广到仪器舱、级间段、整流罩基座。
- 纵向电缆罩：现有 `upperRace` 是一根细长方盒，最显假。改为 Π 形截面沿母线挤出（`ExtrudeGeometry`），每 1.6m 加一个 C 形卡箍（现在每段只有 2 个）。
- 一级贮箱赤道区补保温/隔热毡分块（实例化薄板 + 哑光材质），远处 opticalän surface-breaking detail。

### A3 喷管与尾段（最关键，镜头给得最多）

现状：`bell = LatheGeometry(bellProfile(0.16, 0.42, 1.5), 32)`，单层回转体。改为三层：

1. **喷管本体**：内腔单独 mesh（暗褐碳化材质，双面），外壁沿母线布置 12~16 根再生冷却管（`TubeGeometry`），再在法线贴图上补细密竖条纹，兼顾近看与远看。
2. **涡轮排气管**：真实每台发动机有两根明显的燃气发生器排气管，从燃烧室外侧沿箭体向下外弯出，用 `CatmullRomCurve3` + `TubeGeometry` 生成。芯级四机加助推四台共 8 台，是"照片级差异"最大的单项改动。
3. **摇摆机构**：万向环 + 2 个作动筒（缸体 + 活塞杆），留出接口给模块 B 驱动，实现物理与画面同源。
4. **点火辉光**：腔内加一片叠加混合（AdditiveBlending）圆片，随推力升高变亮，比单纯放大尾焰锥更可信。

命名与挂点必须挂在所属部件组（`coreEngines` 与各自助推器组）下，保证分离时一起走。

## 2. 模块 B：飞行动力学与姿态控制

把 `stepPhysics` 里的解析高度换成逐帧积分与姿态闭环，演示时长与时间线保持不变。

### B1 状态量与积分

```
state = { pos, vel, mass, pitch, yaw, roll, pitchRate, yawRate, rollRate }
```

- **质量**：每阶段给定 `mdot`，积分消耗；关机后归零。参考真实量级：起飞推力约 5920 kN（8 机），海平面比冲约 2560 m/s。
- **推力**：`T = mdot · Isp · g0`，方向沿箭体轴（`dir = quaternion · (0,1,0)`）。
- **重力**：`g(h) = g0 · (R/(R+h))²`。
- **气动阻力**：`ρ(h) = ρ0·exp(-h/8500)`（45 km 以上视为 0）；`D = 0.5·ρ·Cd(M)·A·v²`；`Cd` 跨声速约 0.38，超声速回落到 0.26。
- **积分器**：半隐式欧拉 + 固定步长 `1/120`，用累加器把可变帧长切成固定步；`seek()` 复用同一条代码路径，保证跳转与播放一致。

### B2 时间压缩（重要设计决策）

真实一级约 120 秒才完成重力转弯，而演示窗口只有 34 秒（点火 10 秒到上级分离 44 秒）。

方案：引入 `SIM_SPEED = 2.8`，即每演示秒推进 2.8 个真实秒。效果：

- 演示内 34 秒 ≈ 真实 95 秒，足以完整呈现"垂直上升 → 起转倾斜 → 程序转弯 → 接近入轨姿态"
- HUD 的高度、速度、马赫直接来自积分结果，不再由 `getHud()` 里的另一套公式反算

副作用与处理：`stackSpan()` 与 `cameraOrbit()` 目前假定箭体竖直（见 `launch.js:1320` 附近的 `if (tt >= T_ESC) y1 = 50.3`），必须改为沿箭体轴取包络、注视点在质心，否则倾斜后画面会切掉尾部。

### B3 姿态程序（重力转弯 + 滚转）

- **滚转程序**：离塔后 0~12 秒，由塔架方位平滑转到飞行方位，`ψ(t) = ψ_target · smoothstep(t/12)`，之后锁定并有小幅修正。
- **俯仰程序**：
  - 离塔后前 2 秒：`θ = 0`（垂直）
  - 2~8 秒：以约 1.2 度/秒起转，倾斜到 `θ₀ ≈ 3°`
  - 之后开环：`θ(h) = θ₀ + (θ_end − θ₀) · 正切型过渡`，到约 110 km 时接近 `θ_end ≈ 68°`
- **闭环修正**：目标姿态经 PD 控制器（`Kp ≈ 4.0，Kd ≈ 1.6`）输出角加速度，叠加跨声速湍流扰动（在最大动压点附近振幅最大）。画面上会看到轻微摇摆后被拉回，正是要讲的"姿态修正"。
- **执行机构可视化**：控制器输出直接驱动 A3 的摇摆机构（摆角限幅 ±8 度）与尾焰方向。

### B4 分离动力学增强

保留现有 `safeRadial / safeAxial` 防穿模兜底，另补两项：

1. 相对气流阻力：分离体各自受 `0.5·ρ·Cd·A·v_rel²`，于是助推器会被甩在后面并逐渐减速，这是真实画面里最明显的特征。
2. 翻滚限制：角速度上限加指数阻尼，避免长时间高速自旋显得像陀螺。

## 3. 模块 C：倒计时与实时状态播报

### C1 重构时间基准（解决"图文不同步"的根因）

当前 `main.js:419` 把场景时间绑在 mp3 播放头上。改为：

- **主时钟 = `performance.now()`**，可暂停、可跳转；音频跟随主时钟而不是驱动主时钟。
- 每帧检查：只有当 `|音频播放头 − 期望偏移| > 0.35 秒` 才执行 seek；音频未就绪或被拒播时完全不 seek，直接走合成音兜底。
- 倒数由主时钟派生：`cd = ceil(T_IGN − t)`，大号数字、逐秒提示音、人声层三者消费同一个值。

保留既有资产：`launch-ascent.mp3` 的 10 到 1 人声与点火口令继续作为人声层，只是不再拥有时间主权。

### C2 事件总线与时序器

在 `launch.js` 内新增 `Sequencer`，事件由**飞行状态**触发而不是写死时间点：

- `LIFTOFF`：上升位移大于 0.3 m 且推力已建立
- `MAX_Q`：运行时检测动压由升转降的极值点
- `PITCH_OVER`：指令俯仰角超过 1 度
- `ROLL_DONE`：滚转角进入目标正负 2 度
- `ATTITUDE_CORRECT`：指令与实际姿态偏差超阈后回归，天然触发"姿态修正"播报
- `SEP_ESC / SEP_BOOST / SEP_CORE / FAIRING_OPEN / SOLAR_DEPLOY / SECO / SEP_UPPER / ORBIT`：由实际分离与展开状态触发

兜底：每个事件带 `latestT`，超时仍未触发则按时序表强制补发，防止参数调整后某事件永远不到。

### C3 播报层 Narrator

新增 `NARRATION` 表（建议放独立文件 `src/narration.js`）：

```js
{ id: 'MAX_Q',
  text: '气动载荷最大点已通过，火箭姿态稳定',
  voice: { kind: 'tts' | 'clip' | 'sfx', name: 'sep1' },
  priority: 2, duckDb: -12, minGapSec: 0.9 }
```

- 语音来源分级：
  - 现有人声素材（sep1 / sep2 / sep3）复用给 `SEP_ESC / SEP_BOOST / SEP_CORE`，真人质感最好
  - 新事件用 `window.speechSynthesis`（zh-CN，无需联网）
  - 合成语音不可用时降级为字幕 + 既有合成音（chime / clack）
- 调度器：优先级抢占 + `minGapSec` 抑制重叠；播报时对主音轨做闪避（衰减 12 dB），结束后线性恢复。
- UI：新增字幕条 `#narration`（HUD 下方，沿用现有 `.hud` 样式），显示当前播报文本。

### C4 单一事实来源

`getHud()` 不再自行推导，改为读取来自物理状态的遥测：

```
高度 xx.x km · 速度 xxxx m/s · 马赫 x.x · 动压 xx kPa · 俯仰 xx°
```

阶段指示条、字幕、阶段机共用同一套事件，避免"文字说已分离、画面还没动"的错位。

## 4. 实施顺序与每阶段验收

建议按 A → B → C 推进：建模与动力学互不影响，而 C 的事件定义依赖 B 的状态量，放在最后最稳。

| 阶段 | 内容                       | 验收方式                          |
| -- | ------------------------ | ----------------------------- |
| S1 | A1 贴图组与材质升级（先整流罩、二级，后一级） | 固定机位同光照前后对比截图                 |
| S2 | A2 接缝、电缆罩、对接环            | 尾段与级间段、仪器舱局部特写                |
| S3 | A3 喷管三层、涡轮排气管、摇摆机构       | 尾段俯视特写 + 分离后尾段截图              |
| S4 | B1 状态积分、B2 时间压缩、相机包络改造   | 飞行轨迹数值表（高度、速度、马赫）+ 全程不切尾      |
| S5 | B3 姿态程序、PD 修正、摇摆联动       | 特征时刻姿态角序列 + 摆角截图              |
| S6 | B4 分离气动                  | 分离体相对位置随时间的曲线                 |
| S7 | C1 主时钟重构                 | 回归倒数逐秒对齐误差小于 100 ms；音频缺失时倒数照常 |
| S8 | C2/C3 事件总线、播报器、字幕        | 事件时序表与画面、HUD 逐条核对             |
| S9 | C4 HUD 单一数据源与全流程联调       | 回放截图 + 暂停、跳转、重播回归             |

每阶段结束给一组对比截图和一段简短结论，你确认后再进下一阶段。

## 5. 已确认的决策（2026-09-29）

1. **新事件语音**：浏览器内置合成语音 `window.speechSynthesis`，语种 zh-CN
   - 现有 3 段真人素材 sep1 / sep2 / sep3 继续负责 `SEP_ESC / SEP_BOOST / SEP_CORE`
   - 其余事件（点火、起飞、程序转弯、姿态修正、最大动压、整流罩、太阳翼、二级关机、入轨）走合成语音播报 + 字幕条
   - 降级链路：合成语音不可用 → 字幕 + 既有提示音（chime / clack）
   - 注意点：首次调用需发生在用户手势之后；语速设 `rate ≈ 1.05`；播报期间主音轨闪避 12 dB

2. **尾段建模依据**：按 YF-20B 公开构型做，不再等待补充照片
   - 芯级四机 + 助推四台 = 8 台发动机，每台两根燃气发生器排气管（`CatmullRomCurve3` + `TubeGeometry`）
   - 每台配再生冷却管束（12~16 根）、万向环、两只作动筒、腔内点火辉光片
