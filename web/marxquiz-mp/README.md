# 刷题小程序（纯本地离线版）

> ## ⚠️ 第一步必做：把 AppID 换成你自己的
>
> 打开根目录的 **`project.config.json`**，找到这一行：
>
> ```json
> "appid": "touristappid"
> ```
>
> 把 `touristappid` 换成你自己的小程序 AppID（形如 `wxYOUR_APPID_HERE`）。
> 用 `touristappid` 只能在电脑上预览，**无法上传、无法在手机上长期使用**。
>
> 也可以不改文件：在微信开发者工具右上角「详情 → 基本信息 → AppID」里直接改，工具会自动写回配置。

> ### 🚫 测试号不能上传，也做不了体验版
>
> 开发者工具里那个「测试号」（AppID 形如 `wx` + 16 位、在工具里标着"测试号"）**只能跑模拟器调试**：
> 没有「上传」按钮、不能预览到手机、更不能设为体验版。
>
> 想在手机上长期使用，必须有**正式的小程序 AppID**。个人主体注册免费、全程线上、约 10 分钟：
>
> 1. 打开 <https://mp.weixin.qq.com> → 右上角「立即注册」→ 选 **小程序**
> 2. 填一个**没注册过公众平台的邮箱** → 收邮件激活
> 3. 主体类型选 **个人** → 身份证信息 + 管理员微信扫码验证（不需要营业执照、不收费）
> 4. 进后台「设置 → 基本设置」，把 **名称、头像、简介、服务类目** 填一下
>    - 名称全平台唯一，重名要换一个；个人主体可选类目有限，挑一个能选中的即可
>    - 体验版不走审核，类目只影响以后正式发布，随便选不会卡住体验版
> 5. 在「设置 → 开发设置」里复制 **AppID**，回到开发者工具「详情 → 基本信息」填进去
>
> 个人主体不需要微信认证就能上传代码和设体验版；本小程序**不使用任何隐私接口**（没有定位、相册、手机号、用户信息），所以也不用配「用户隐私保护指引」。

## 一、三步跑起来

### 第 1 步：导入项目

1. 下载安装 **微信开发者工具**（稳定版即可）。
2. 打开工具 → 扫码登录 → 左侧选「小程序」→ 点 **「＋」→ 导入项目**。
3. **目录**：选择本文件夹 `quiz-miniprogram`（就是含 `app.json` 的这一层）。
4. **AppID**：填你自己的 AppID（见上方红字说明）。
5. 后端服务选「不使用云服务」，点「导入」。

### 第 2 步：点「编译」看效果

工具顶部点 **「编译」**，模拟器里就会出现「我的题库」首页。

**首次启动会自动带入 7 个内置题库（《马克思主义基本原理》912 题，每题带完整解析）**，直接点卡片就能刷：

| 题库 | 题数 |
| --- | --- |
| 马原·导论 | 23 |
| 马原·第一章 | 294 |
| 马原·第二章 | 157 |
| 马原·第三章 | 276 |
| 马原·第四章 | 120 |
| 马原·第五章 | 17 |
| 马原·第六七章 | 25 |
| **合计** | **912**（单选 424 / 多选 173 / 判断 315） |

内置题库只在**首次启动时写入一次**，写入前会按题库名查重——所以你之前加载过的「示例题库」不会阻碍它，也不会重复导入。写入后就是普通题库，可以重命名、删除、练错题；删掉后不会再自动冒出来。

- 点 **「加载示例题库」** 另外拿到 20 道演示题（四种题型齐全，含填空），用于试功能。
- 想加自己的题库：点「＋ 导入题库」→ 粘贴内容 / 从聊天选文件 / 加载示例。

### 第 3 步：上传 → 设为体验版 → 手机扫码

1. 确认开发者工具「详情 → 基本信息」里的 AppID 是**正式 AppID**（不是测试号、不是 `touristappid`），否则右上角不会出现「上传」按钮。
2. 工具右上角点 **「上传」**，版本号填 `1.1.0`，备注随意，确定。
3. 打开 <https://mp.weixin.qq.com>（小程序管理后台）→ 左侧 **「管理 → 版本管理」**。
4. 在「开发版本」里找到刚上传的版本 → 点 **「选为体验版」**。
5. 在「体验版」区域会生成一个 **二维码**，用手机微信扫它即可打开。
6. 想长期使用：把这个二维码保存下来；也可以在「成员管理 → 体验成员」里添加其他微信号一起用。

> **第一次在手机上打开时，会自动写入 7 个题库共 912 题**，不需要手动导入。
> 之后你在手机上刷的进度、错题，都只存在这台手机里。
>
> 注意：微信的本地存储按「小程序 + 微信用户」维度存放，**开发版 / 体验版 / 正式版共用同一套**。
> 也就是说你在「预览」里刷的进度，切到体验版之后依然在，不会重置。

## 二、关于「体验版」你需要知道的

| 问题 | 答案 |
| --- | --- |
| 需要提交审核吗？ | **不需要。** 体验版不经过审核流程。 |
| 需要上架到微信「发现-小程序」吗？ | **不需要，也不会上架。** 只有你自己和体验成员能看到。 |
| 会过期吗？ | 体验版**版本**长期有效，但**二维码约 7 天过期**（弹窗里会写明截止日期）。过期后回「版本管理」重新点「扫码访问体验版」拿新码即可。 |
| 测试号能做体验版吗？ | **不能。** 测试号只能跑模拟器，必须先注册正式 AppID（见文首说明）。 |
| 手机没网能用吗？ | **能。** 本小程序零网络请求，全部数据在本地。 |
| 换手机/卸载微信会丢数据吗？ | 会。数据存在本机，请用「设置 → 备份全部数据」定期备份。 |
| 只有自己能扫码吗？ | 默认只有开发者本人 + 「体验成员」列表里的人能扫开。 |
| 改了代码要重新上传吗？ | 要。每次改完都要重新「上传」并在后台重新「选为体验版」。 |

## 三、题库格式说明

三种格式都支持，导入时会**自动识别**，不用手选。

### 3.1 JSON（推荐，最不容易出错）

```json
{
  "name": "计算机基础",
  "questions": [
    {
      "type": "single",
      "stem": "1 字节等于多少位？",
      "options": [
        { "key": "A", "text": "4 位" },
        { "key": "B", "text": "8 位" },
        { "key": "C", "text": "16 位" },
        { "key": "D", "text": "32 位" }
      ],
      "answer": "B",
      "analysis": "1 Byte = 8 bit。",
      "tags": ["计算机"]
    },
    {
      "type": "multiple",
      "stem": "下列属于操作系统的有？",
      "options": [
        { "key": "A", "text": "Windows" },
        { "key": "B", "text": "Linux" },
        { "key": "C", "text": "Photoshop" },
        { "key": "D", "text": "macOS" }
      ],
      "answer": ["A", "B", "D"],
      "analysis": "Photoshop 是图像处理软件。",
      "tags": ["计算机"]
    },
    {
      "type": "judge",
      "stem": "1 KB 等于 1024 字节。",
      "options": [
        { "key": "A", "text": "正确" },
        { "key": "B", "text": "错误" }
      ],
      "answer": "A",
      "analysis": "二进制计量体系。",
      "tags": []
    },
    {
      "type": "fill",
      "stem": "中国的首都是____。",
      "options": [],
      "answer": ["北京"],
      "analysis": "中华人民共和国首都是北京。",
      "tags": ["地理"]
    }
  ]
}
```

字段说明：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `type` | 否 | `single` / `multiple` / `judge` / `fill`，也可写「单选/多选/判断/填空」。不写会自动推断 |
| `stem` | **是** | 题干。也可写 `question` / `title` / `content` / `题目` / `题干` |
| `options` | 选择题必填 | 三种写法都行：`[{key,text}]`、`["甲","乙","丙"]`、`{"A":"甲","B":"乙"}`；也可以用独立字段 `A`/`B`/`C`/`D`、`optionA`、`选项A` |
| `answer` | **是** | 单选/判断写字符串，多选写数组（升序），填空写字符串数组（任一命中即算对）。也接受 `A、C`、`A,C`、`AC` 这类写法 |
| `analysis` | 否 | 解析，也可写 `explain` / `解析` |
| `tags` | 否 | 标签数组，也可写字符串 `"计算机,基础"` |

> `id` 不用写，导入时会自动生成（`q_序号_题干hash`），重复导入同一份题库 id 保持稳定。
> 判断题的选项固定为「A 正确 / B 错误」，答案写 `A`/`B` 或 `正确`/`错误` 都可以。

### 3.2 TXT（最适合从 Word 里复制出来）

```
一、单选题

1. 下列哪一项是中国的首都？
A. 上海
B. 北京
C. 广州
D. 深圳
答案：B
解析：北京是中华人民共和国的首都。
标签：地理

2、计算机中 1 字节（Byte）等于多少位（bit）？
A、4 位
B、8 位
C、16 位
D、32 位
正确答案: B
解析：1 Byte = 8 bit。

二、多选题

3. 下列属于操作系统的有？
A) Windows
B) Linux
C) Photoshop
D) macOS
答案：ABD
解析：Photoshop 不是操作系统。

三、判断题

4. 地球是太阳系中距离太阳最近的行星。
答案：错误
解析：距离太阳最近的是水星。

四、填空题

5. 中国的首都是____。
答案：北京
```

宽松解析规则：

- 题号行支持 `1.` `1、` `(1)` `第1题`
- 选项行支持 `A.` `A、` `A)` `A．` `A:`
- 答案行支持 `答案：A` `答案:A` `正确答案：A` `答案：AB`（多选连写也行）
- 解析行支持 `解析：xxx`，可以多行
- 没有选项的题自动判为**填空**；只有两项且内容是「正确/错误」「对/错」的自动判为**判断**
- `一、单选题` 这类章节标题会被识别，其下没写题型的题自动套用该题型
- 空行随便加，不影响

完整可导入示例见 `sample/bank-sample.txt`（5 题，四种题型齐全）。

### 3.3 CSV（适合从 Excel 另存为 CSV）

```csv
题型,题干,选项A,选项B,选项C,选项D,答案,解析,标签
单选题,水的化学式是？,CO2,H2O,O2,NaCl,B,一个水分子由两个氢原子和一个氧原子构成,科学
多选题,下列属于操作系统的有？,Windows,Linux,Photoshop,macOS,ABD,Photoshop 不是操作系统,计算机
判断题,1 KB 等于 1024 字节。,,,,,正确,二进制计量体系,计算机
填空题,中国的首都是____。,,,,,北京,,地理
```

- 表头列名容错：`题型/type`、`题干/题目/question`、`选项A~D/optionA~D/A~D`、`答案/answer`、`解析/解析/explain`、`标签/tags`
- 字段里含逗号时用英文双引号包起来，例如 `"下列属于""前端""技术的有？"`
- 判断题的选项列留空即可

> 完整 20 题示例见 `sample/bank-sample.json`。

## 四、Excel / Word 题库怎么转

小程序里**读不了** `.xlsx` 和 `.docx`，需要先在电脑上转成 `.json`。

### 4.1 用自带脚本（推荐）

需要电脑装了 Python 3。

```bash
# 1) 装依赖（只需装一次；只转 txt/csv 可以跳过这步）
pip install openpyxl python-docx

# 2) 转换
python tools/convert.py 题库.xlsx -o bank.json
python tools/convert.py 题库.docx -o bank.json
python tools/convert.py 题库.txt  -o bank.json
python tools/convert.py 题库.csv  -o bank.json
```

- 路径含空格请加引号：`python tools/convert.py "D:\我的题库\计算机 基础.xlsx" -o bank.json`
- 想自定义题库名：加 `-n "计算机基础"`
- `.xlsx` 只读**第一个工作表**，会自动在前 10 行里找表头（表头需包含「题干」或「题目」）
- `.docx` 会优先尝试读取**第一个表格**（按表头映射）；如果文档里没有表格，就按上面 TXT 的分段规则解析段落
- 转换完会打印题目数量和被跳过的题目原因，方便你回头修表格

Excel 表格建议长这样（第一行是表头）：

| 题型 | 题干 | 选项A | 选项B | 选项C | 选项D | 答案 | 解析 | 标签 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 单选题 | 水的化学式是？ | CO2 | H2O | O2 | NaCl | B | 一个水分子由两个氢原子和一个氧原子构成 | 科学 |
| 多选题 | 下列属于操作系统的有？ | Windows | Linux | Photoshop | macOS | ABD | Photoshop 不是操作系统 | 计算机 |
| 判断题 | 1 KB 等于 1024 字节。 | | | | | 正确 | 二进制计量体系 | 计算机 |
| 填空题 | 中国的首都是____。 | | | | | 北京 | | 地理 |

### 4.2 把 .json 送进手机

1. 把生成的 `bank.json` 通过 **微信「文件传输助手」** 发给自己（或发给任意好友）。
2. 手机打开小程序 → 首页「＋ 导入题库」→ 切到 **「从聊天选文件」** → 选择那个 `.json`。
3. 自动解析出预览，确认无误后点「确认导入」。

> 也可以直接在电脑上打开 `.json` 复制全部文本，用 **「粘贴导入」** 粘贴进去。

### 4.3 懒得转换？

把 Excel / Word 文件发给 AI 助手，说「按这个格式帮我转成 JSON 题库」，把结果粘贴进「粘贴导入」即可。

## 五、界面与功能说明

### 视觉风格

- 配色：柔和浅薄荷绿（`#F3FAF6` 底 / `#A9E5CB` 点缀）+ 亮柠绿（`#C9F26E` 主操作）+ 纯黑（`#0F1115` 文字与强调）
- 圆角：卡片 30–38rpx，按钮全部胶囊形（`999rpx`）
- 阴影：轻新拟态 —— 极淡外阴影 + 1rpx 内高光，卡片像浮在纸面上
- 留白：页面左右 32–40rpx，卡片内边距 30rpx 以上，信息密度低
- 装饰：仅顶部两枚低透明度圆形色块，无多余线条与图标
- 深浅两套配色同时维护，深夜模式不是简单反色，而是深墨绿底 + 提亮的柠绿


### 四种刷题模式

点首页题库卡片后弹出：

| 模式 | 行为 |
| --- | --- |
| 顺序刷题 | 按题库原顺序，逐题作答，提交后立刻看对错和解析 |
| 随机刷题 | 打乱顺序，其余同上 |
| 只刷错题 | 只练这个题库里答错过的题；在错题模式下答对会自动移出错题本 |
| 模拟考试 | 限时 60 分钟，**提交后不显示对错和解析**，交卷后统一在结果页看解析；可提前交卷 |

### 答题交互

- 单选 / 判断：点选高亮 → 点「提交」才判对错（避免误触直接跳题）
- 多选：可多选，提交后判对错，必须与正确答案完全一致
- 填空：输入框作答，答案数组中任一命中即算对（不区分大小写和首尾空格）
- 提交后：正确项标绿、选错项标红，展示正确答案与解析
- 右上角「答题卡」：网格看全卷状态（未答/已答/答对/答错），点题号跳转
- 退出自动保存进度；下次进同一题库同一模式会问「继续上次进度 / 重新开始」

### 答对自动跳下一题

- 默认**开启**，延时 **800ms**（可在「设置 → 答题」里改成 400 / 800 / 1500ms，或关闭）
- **答错不会自动跳**，会停住让你看解析
- **模拟考试模式强制不自动跳**
- 最后一题答对不跳，提示「已是最后一题，可以交卷」

### 白昼 / 深夜主题

- 首页右上角 🌙 / ☀️ 按钮：一键在两种主题间切换
- 「设置 → 外观」：白昼 / 深夜 / **跟随系统** 三选一
- 选择「跟随系统」时，手机切换深色模式小程序会实时跟着变
- 偏好会持久化，下次打开自动恢复

### 数据安全

「设置 → 数据」里：

- **备份全部数据**：把全部题库、进度、错题、收藏打包成 JSON 复制到剪贴板 → 粘贴到备忘录/聊天窗口长期保存
- **从备份恢复**：从剪贴板读回备份，二次确认后覆盖恢复
- **清空所有数据**：双重确认 + 需手动输入「删除」两字才会执行

单个题库也可以单独导出：首页卡片右侧「⋯ → 导出到剪贴板」。

## 六、常见问题

### Q0. 编译后首页还是「还没有题库」

内置题库在 `app.js` 的 `onLaunch` 里写入，正常编译一次就会出现 7 个题库卡片。如果还是空的：

1. **先点空态页的「一键载入内置题库（912 题）」按钮** —— 这是手动入口，绕过所有自动判断，必定生效。
2. 若按钮提示「载入失败」，按弹窗里的错误信息排查（最常见是开发者工具编译报错，见下一条）。
3. 确认底部调试器 Console 没有红色报错。若 `utils/banks/` 下有文件报错，说明文件不完整，重新拷贝一次项目。
4. 菜单「工具 → 清缓存 → 全部清除」后再点「编译」。

> 说明：内置题库只在**首次成功写入**后打标记（`app:seeded`）。写入失败不会打标记，下次启动会自动重试，所以不需要你手动删缓存。

### Q0.5 能不能和别的小程序共用一个 AppID 的体验版？

**不能。** 一个 AppID 下体验版只有一个，它是指向某个开发版本的「单一指针」：

- 同一个 AppID 上传本项目的代码并「选为体验版」→ 原来那个项目的体验版会被**顶掉**
- 两个项目无法同时拥有体验版，只能二选一

解决办法：**再注册一个小程序**。个人主体最多可注册 **5 个**小程序，一个微信号最多当 5 个的管理员，额度通常够用。

注册需要准备一个**没注册过公众平台的新邮箱**（同一个邮箱不能重复注册），其余和第一次一样：身份证 + 微信扫码，免费。

> 只要不点后台的「**发布**」，上传 / 设为体验版都不会影响同一个 AppID 下的线上正式版。

### Q1. 真机预览打不开 / 扫码提示「无权限」
- 确认 AppID 已经换成你自己的（不能用 `touristappid`）。
- 在后台「管理 → 成员管理 → 体验成员」里，把你的微信号加进去。
- 确认手机上微信已登录**同一个微信号**（扫码用的号和开发者号一致最稳）。
- 体验版二维码要用**手机微信**扫，不能长按识别后在小程序里打开。

### Q2. 点「上传」提示没有权限

- 说明当前 AppID 对应的账号里，你这个微信号不是开发者。
- 去后台「管理 → 成员管理 → 项目成员」，把自己加为「开发者」或「运营者」。
- 也可能是 AppID 填错了（填成了别人的或体验用的 AppID）。

### Q3. 题库丢失了怎么恢复

1. 「设置 → 数据 → 从备份恢复」，先试试剪贴板里有没有之前的备份。
2. 没有备份就只能重新导入（题库内容本身还在你的 Excel/Word/JSON 文件里）。
3. **养成习惯**：每次导入完新题库，去设置页点一次「备份全部数据」，把文本粘贴到微信「文件传输助手」发给自己。

> 注意：在开发者工具里点「清缓存 → 清除全部缓存」会清掉本地数据，操作前请先备份。

### Q4. 存储上限是多少

- 小程序本地存储上限是 **10MB**（所有 key 加起来）。
- 纯文字题库非常省空间：1 道题大约 200～500 字节，**1 万道题大概 2～5MB**，一般够用。
- 「设置 → 关于」里能看到当前占用。
- 如果提示「存储空间不足」：删掉不用的题库，或清理错题本。

### Q5. 导入时提示「JSON 格式有误」

常见原因：

- 用了**中文引号** `“”`，必须改成英文 `"`
- 最后一个元素后面多了逗号
- 少了逗号或括号不配对

最省事的办法：把内容发给 AI 助手，说「帮我检查并修正这个 JSON 题库」。

### Q6. 导入后题型不对 / 判断题变成填空题

- 判断题需要**两个选项**（正确/错误）。如果原文没写选项，就会被当成填空题。
- 手动加 `题型：判断题`，或写成 `答案：正确` 也行（有选项时才能识别为判断题）。
- JSON 里显式写 `"type": "judge"` 最稳。

### Q7. 深夜模式下有地方还是白底

本项目的所有颜色都走 CSS 变量（定义在 `app.wxss` 的 `.page.theme-light` / `.page.theme-dark`）。
如果自己改过 WXSS 引入了硬编码颜色（如 `background:#fff`），深夜模式就会露白 —— 改回 `var(--card)` 即可。

## 八、技术说明（想改代码时看）

- **零依赖**：原生小程序（WXML/WXSS/JS/JSON），不用 npm、不用构建、不用 TS、不引第三方 UI 库。
- **零网络**：全项目没有 `wx.request`，没有云开发，没有 `wx.login`。数据只在本机。
- **零图片资源**：所有图标都是 emoji 或纯 CSS，所以包体积极小。
- **存储**：全部收敛在 `utils/store.js`，key 约定：
  - `qb:list` 题库列表
  - `qb:data:<id>` 题目数组
  - `qb:progress:<id>` 练习进度
  - `qb:wrong:<id>` 错题
  - `qb:fav:<id>` 收藏
  - `qb:stat:<id>` 答题统计
  - `app:theme` 主题偏好
  - `app:settings` 答题设置
  - `app:meta` 元信息（版本、上次备份时间）
- **解析器**可直接用 Node 测试：

  ```bash
  node -e "const p=require('./utils/parser.js'); console.log(p.parse('1. 题干\nA. 甲\nB. 乙\n答案：A'))"
  ```

- WXSS 兼容性：不使用 `gap`（用 margin）、不使用 `:has()`、不使用 `position: sticky`，保证低版本基础库也能正常渲染。

## 九、已知限制

1. 小程序本地存储上限 10MB，题库特别大（十万题以上）时需要注意。
2. 数据只存在本机，换手机 / 卸载微信 / 清除缓存都会丢，务必定期备份。
3. 小程序内不能直接解析 `.xlsx` / `.docx`，必须先在电脑上转成 `.json`。
4. 选择题选项最多支持到 `H`（8 个）。
5. 填空题按「任一答案命中即对」判定，不支持模糊匹配或多空分步填写。
6. 错题本按题库隔离，不提供跨题库的全局错题练习。
