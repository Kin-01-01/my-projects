从大一拿下 Python 计算机二级开始，到自学 Andrew Ng 的机器学习课程、备考数据库方向的三级，再到进新能源材料实验室做电解水制氢，我给自己搭了一套能跑起来的学习系统。

这个站点就是这套系统的对外版本：把路线、项目、笔记和每周复盘摊开，既是对自己的交代，也希望能帮到同样在非科班逆袭的人。

实验室方向

新能源材料组，聚焦电解水制氢与电极材料。

我负责把实验数据跑成可解释的图表，也参与电极配方的初步筛选。物理底子帮我更快理解催化机理，代码则把重复劳动交给机器。

这段经历让我确信：交叉背景不是劣势，反而是差异化。

团队项目 · 熵减

「熵减（Entropy↓）」是一个校园减碳项目：微信小程序 + 腾讯云 CloudBase，覆盖校区碳排放监测与减碳建议。我承担前端与数据部分，把课堂学的东西真正用到了产品里。

它也是我理解「工程化」的入口：从本地脚本到上线服务，中间差的不只是代码，还有部署、维护与用户。
