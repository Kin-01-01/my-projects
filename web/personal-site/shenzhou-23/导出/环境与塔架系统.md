# 发射环境系统 & 脐带塔系统（模块化设计与参数边界）

> 新增模块：`src/environment.js`（大气/重力/风场/气象）、`src/tower.js`（脐带塔建模与机构）。
> 设计目标：物理可信、可校验、可维护；资源占用可控；所有参数有明确取值范围与异常兜底。

---

## 一、模块边界

```
environment.js                           tower.js
├─ ENV_BOUNDS        参数取值范围表       ├─ TOWER_SPEC   塔体规格
├─ temperatureAt(h)  温度 K               ├─ buildTower({siteMats, spec})
├─ pressureAt(h)     气压 Pa              │    → { group, arms, armLines, holddowns,
├─ densityAt(h)      密度 kg/m³           │        lights, levels, mats, update, armsClear, stats }
├─ soundSpeedAt(h)   声速 m/s             │
├─ gravityAt(h)      重力 m/s²            │  update(t, {lifted, liftT})
├─ windAt(h, t)      风速/风向/阵风/切变   │  armsClear(t) → 互锁校验
├─ stepWeather(dt)   气象演进（节流）      └─ stats()      → 资源占用统计
├─ setWeatherPreset(name) / weatherState()
├─ envSample(h, v, t)  零分配综合采样
└─ atmosphereProfile() 分层概要（非逐帧）
```

`launch.js` 接入点：`stepAscent()` 用 `ENV.gravityAt / ENV.densityAt`；`stepPhysics()` 每帧
`ENV.stepWeather(dt)` + `ENV.envSample(...)`；烟尘/余烬按 `envNow.windX/windZ` 漂移；
塔机构由 `R.towerMod.update(t, {lifted, liftT})` 驱动。

## 二、大气分层模型（US Standard Atmosphere 1976）

**分层公式**（位势高度 `z = Re·h/(Re+h)`，`Re = 6 356 766 m`）：

```
温度：  T(z) = T_b + L·(z − h_b)                       （L 单位 K/km）
气压：  L ≠ 0： p = p_b · (T_b / (T_b + (L/1000)·Δz))^(g0·M /(R*·(L/1000)))
        L = 0： p = p_b · exp( −g0·M·Δz / (R*·T_b) )     （等温层指数律）
密度：  ρ = p /(R_air·T)                                （状态方程，与 T、p 自洽）
声速：  a = √(γ·R_air·T)，γ = 1.4
```

| 层底 h_b (km) | 递减率 L (K/km) | T_b (K) | p_b (Pa) |
|---|---|---|---|
| 0 | −6.5 | 288.15 | 101 325 |
| 11 | 0 | 216.65 | 22 632.06 |
| 20 | +1.0 | 216.65 | 5 474.889 |
| 32 | +2.8 | 228.65 | 868.019 |
| 47 | 0 | 270.65 | 110.906 |
| 51 | −2.8 | 270.65 | 66.939 |
| 71 | −2.0 | 214.65 | 3.956 |

84.852 km 以上按等温 + 标高 6 km 指数外推（ρ→0，避免"永远有大气"）。

**实测校验**（模型 vs 标准值，误差来自"几何高度 ↔ 位势高度"换算差异）：

| 高度 | 温度 | 气压 | 密度 |
|---|---|---|---|
| 0 km | 288.15 K (0.00%) | 101 300 Pa (0.02%) | 1.225 (0.02%) |
| 11 km | 216.77 K (0.06%) | 22 698 Pa (0.29%) | 0.365 (0.23%) |
| 20 km | 216.65 K (0.00%) | 5 529 Pa (0.99%) | 0.0889 (1.00%) |
| 32 km | 228.49 K (0.07%) | 889 Pa (2.42%) | 0.01356 (2.53%) |
| 50 km | 270.65 K (0.00%) | 79.8 Pa (0.00%) | 1.027e−3 (0.01%) |

## 四、风场模型

```
① 近地面对数律（0 ~ 200 m）： u(h) = u10 · ln((h+z0)/z0) / ln((10+z0)/z0),  z0 = 0.03 m
② 200 m ~ 急流层：         u(h) = u200 + (u_jet − u200)·G(h)·clip((h−200)/(h_jet−200), 0, 1)
                           G(h) = exp( −((h − h_jet)/3500)² )        高斯急流峰
③ 20 km 以上：             u ← u · exp(−(h−20 000)/28 000)，并有 4 m/s 下限残余
④ 阵风：  gust = (0.55 sin(0.9t + 4e−4·h) + 0.30 sin(2.3t + 1.1e−3·h)
                  + 0.15 sin(5.1t + 2.7e−3·h)) · I_turb · (2 + 0.12·u)
⑤ 切变：  shear = |gust| / max(u,1)     湍流：I = I_turb·(0.35 + 0.65·exp(−((h−h_jet)/4000)²) + 0.40·e^(−h/400))
⑥ 风向随高度偏转： θ(h) = θ0 + 0.61·clip(h/h_jet, 0, 1.2)   （地面→急流层约 35°）
```

实测：地面 0.8 m/s（标准预设 u10=3.2）、急流层 10.5 km ≈ 26.6 m/s、60 km ≈ 0.7 m/s。

## 五、气象动态（均值回归随机游走）

```
x_{k+1} = clamp( x_k + (μ − x_k)·λ·Δt + U(−span/2, span/2)·Δt , lo, hi )
```

| 变量 | μ（均值） | span | λ | 范围 |
|---|---|---|---|---|
| 云量 | 0.28 | 0.10 | 0.05 | 0 ~ 1 |
| 能见度 | 26 000 m | 2 200 | 0.05 | 800 ~ 60 000 |
| 降水 | 0.0 | 0.06 | 0.15 | 0 ~ 1 |
| 湍流强度 | 0.35 | 0.18 | 0.06 | 0 ~ 1 |
| 温度偏差 | 0 K | 0.9 | 0.04 | −12 ~ +12 |
| 场面气压 QNH | 1013 hPa | 1.2 | 0.05 | 950 ~ 1060 |
| 地面风 u10 | 3.2 m/s | 1.4 | 0.07 | 0 ~ 25 |
| 急流峰值 | 28 m/s | 3.0 | 0.04 | 0 ~ 80 |
| 急流高度 | 10.5 km | 0.5 | 0.04 | 8 ~ 14 |

**节流策略**：内部累计计时，≥0.5 s 才更新一次；单步上限 2 s（快进时不跳变）→ 逐帧开销 ≈ 0。
**预设**：`standard / clear / overcast / gale`（地面风 3.2 / 1.5 / 7.5 / 18 m/s），供脚本或面板一键切换。
天气对物理的反哺：温度偏差按 `e^(−h/8000)` 衰减叠加、QNH 按 `e^(−h/9000)` 修正低空气压。

## 六、脐带塔系统

### 6.1 结构分层（`TOWER_SPEC`）

| 项 | 值 | 说明 |
|---|---|---|
| 塔高 | 62 m | 与"程序转弯需越过塔顶"的安全约束一致 |
| 四腿格构 | 半宽 1.55 m，柱截面 0.55 m | 深蓝钢结构 |
| 层高 | 4.0 m | 横撑 + X 斜撑 |
| 平台层 | 12/20/28/36/44/52 m | 依次对应：助推器段 / 一级段 / 级间段 / 二级段 / 整流罩段 / 飞船段 |
| 摆杆层 | 8 / 15.4 / 22.8 / 30.2 / 37.6 / 45.0 / 52.4 m | 7 层（含脐带管线） |
| 支撑压紧机构 | 4 组，h=1.15 m | 解锁瞬间释放 |
| 泛光灯 | 3 盏 | 数量受控（点光源越多越贵） |

### 6.2 机构时序与约束

```
摆杆： t=2 s 起，自下而上分批： k_i = smoothstep(2 + 0.55i, 6.5 + 0.55i, t)
       角度 = k_i · 2.0 rad（≈115°，向 +Z 侧摆离，远离箭体）
       管线： 摆离角 > 0.8 rad 视为脱开并隐藏（杜绝"跨空连接"穿帮）
支撑臂：解锁后 0.6 s 内摆开并下沉 0.25 m；未起飞时始终压紧
互锁：  armsClear(t) 校验全部摆杆 k ≥ 0.85；若起飞时未撤清 → 强制收尾 + console.warn（只报一次）
```

姿态**仅由 t 决定**（无额外状态）→ `seek()`/重置自动回位，不会残留脏状态。

### 6.3 性能与可维护性

| 指标 | 改造前（内联） | 改造后（模块 + 实例化） |
|---|---|---|
| 塔体网格数 | ≈250 | **52** |
| 其中实例化 | 0 | **5**（横撑×2 / 斜撑 / 护栏立柱 / 横栏×2） |
| 全场景网格 | 1 190 | **1 014** |
| 投影阴影 | 全部构件 | 仅塔柱/平台（构件 `castShadow=false`） |
| 光源 | 3 | 3（未增加） |

可维护性：塔体所有尺寸集中在 `TOWER_SPEC`；`buildTower()` 返回 `stats()` 供巡检；

## 七、参数取值范围、边界条件与异常处理

### 7.1 取值范围（`ENV_BOUNDS`，同时供面板/调用方校验）

| 参数 | 单位 | 下限 | 上限 | 越界行为 |
|---|---|---|---|---|
| 高度 `altM` | m | 0 | 200 000 | 夹紧 |
| 温度 `tempK` | K | 150 | 360 | 夹紧 |
| 气压 `presPa` | Pa | 0 | 120 000 | 夹紧 |
| 密度 `densKgM3` | kg/m³ | 0 | 1.5 | 夹紧 |
| 重力 `gravMs2` | m/s² | 8.5 | 9.9 | 夹紧 |
| 风速 | m/s | 0 | 120 | 夹紧 |
| 地面风 `windSurfaceMs` | m/s | 0 | 25 | 夹紧 |
| 急流峰值 / 高度 | m/s / km | 0 / 8 | 80 / 14 | 夹紧 |
| 湍流强度 | — | 0 | 1 | 夹紧 |
| 云量 / 降水 | — | 0 | 1 | 夹紧 |
| 能见度 | m | 800 | 60 000 | 夹紧 |
| 温度偏差 | K | −12 | +12 | 夹紧 |
| QNH | hPa | 950 | 1060 | 夹紧 |

### 7.2 异常处理策略

| 异常输入 | 行为 |
|---|---|
| `NaN` / `Infinity` / `undefined` | 回落到该量默认值（如温度 → 288.15 K，气压 → 101 325 Pa，风速 → 0） |
| 负高度（如 −500 m） | 夹紧到 0 m（场面标准值） |
| 超大高度（1e12 m） | 夹紧 200 km，密度 ≈ 3.2e−14（趋零但永不为 NaN） |
| `dt ≤ 0` 或非有限 | `stepWeather` 直接返回，不叠加 |
| 快进（单帧 Δt 很大） | 气象单步上限 2 s；风场为解析式，不积分 → 无累积误差 |
| 塔架参数缺省/非法 | `num(v, fallback)` 回落 `TOWER_SPEC` |
| 起飞时摆杆未撤清 | 互锁：强制摆离 + `console.warn`（不中断演示） |

**统一原则**：模块对外**永不返回 NaN**（历史上火焰着色器因 NaN 导致整层不可见），
所有除法都有 `max(x, ε)` 保护，所有输出都经过 `clampB()`。

## 八、接入后的物理表现（实测）

| 演示时刻 | 锁台 | 真实高度 | 竖直速度 | g | ρ/ρ₀ | 风 | 马赫 | 动压 |
|---|---|---|---|---|---|---|---|---|
| 11.0 s | 是 | 0 km | 0 | 9.807 | 1 | 0.5 m/s | 0 | 0 |
| 13.2 s | **否（已解锁）** | 0 km | 0 | 9.807 | 1 | 0.5 m/s | 0 | 0 |
| 30 s | — | 0.47 km | 59 m/s | 9.805 | 0.96 | 5.3 m/s | 0.17 | 2.0 kPa |
| 70 s | — | 6.71 km | 271 m/s | 9.786 | 0.50 | 8.0 m/s | 0.86 | **22.4 kPa（接近 max-Q）** |
| 120 s | — | 30.75 km | 742 m/s | 9.712 | 0.013 | 3.7 m/s | 2.45 | 4.5 kPa |
| 170 s | — | 88.03 km | 1 651 m/s | 9.541 | 3.3e−6 | 0.2 m/s | 6.02 | 6 Pa |

- **离塔时刻未变**（t≈13.05 s，即点火后 ≈3.05 s）：因为解锁判据中 `v=0` 时阻力为 0。
- 阻力项 `a_drag = ½ρv²·Cd·A / m`（Cd=0.32、A=11 m²）在 6~7 km 达到约 0.9 m/s²，**量级与真实火箭同阶**。
- 动压在 t≈70 s 达到峰值 ≈22 kPa，符合真实"最大动压出现在 8~13 km"的规律。

## 九、天空穹顶：随高度分层的渐变与气辉（`src/sky.js`）

### 9.1 结构

一个 BackSide 球（r=5000）+ **无贴图 ShaderMaterial**（1 次 draw call、0 纹理开销），
颜色由三个 uniform 驱动：`uZenith`（天顶色）/ `uHorizon`（地平线色）/ `uGlow`（气辉强度）。
原本烘焙在不透明贴图里的暗夜渐变，改为 **加色叠加层**（`skyDome`），不再遮挡动态天空。

### 9.2 高度分层关键帧（`SKY_KEY`，改颜色只动这张表）

| t（0 地面 → 1 入轨） | 对应高度 | 天顶色 | 地平线色 | 气辉 |
|---|---|---|---|---|
| 0.00 | 地面 | #04070e | #16233a | 0.38 |
| 0.12 | ≈1~3 km | #03050c | #121e34 | 0.31 |
| 0.30 | ≈5~10 km | #02040a | #0d162c | 0.22 |
| 0.55 | ≈20~40 km | #010308 | #070c20 | 0.12 |
| 0.78 | ≈60 km | #000205 | #04081a | 0.06 |
| 1.00 | 入轨 | #000001 | #020410 | 0.025 |

### 9.3 着色与物理

```glsl
up   = clamp(vDir.y, 0, 1)
col  = mix(uHorizon, uZenith, pow(up, uPow))          // uPow = 0.55
col  = mix(col, uHorizon*0.75, pow(-vDir.y, 0.9))     // 下方略压暗，避免"发光地面"
col += uGlowColor * uGlow * exp(-|vDir.y| * 7.0)      // 地平线气辉细带
```

气辉强度按 **大气密度衰减**（瑞利散射 ∝ ρ）：`glowK = (0.35 + 0.65·(ρ/ρ0)^0.25)·(1 − 0.25·云量)`，
密度由 `environment.js` 提供 → 高空大气稀薄时天空自然转黑，与地球弧形/星空同源过渡。

### 9.4 一致性措施

- 驱动量 `skyT = clamp(sceneY/900, 0, 1)`，与既有的 `atm ↔ space` 过渡（站点淡出、地球弧形、星空）**同源**，不会出现"天还蓝着却满天星"。
- **雾色跟随天空地平线色**：`scene.fog.color = skyGrad.horizonColor()`，近景与天空同调，避免割裂。
- **云量耦合**：云量高时星空透明度按 `(1 − 0.55·云量)` 压暗、气辉发灰（阴天看不到星）。
- 调色板插值做了 0.002 阈值节流；uniform 复用 Color 对象，**零逐帧分配**。
