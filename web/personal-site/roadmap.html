L1 · 入门地基
学习要点
  • 二级已拿，重点练文件读写、函数与类、异常处理。
  • 刷《Python Crash Course》习题，养成手写代码习惯。
  • 熟悉虚拟环境与 pip，能独立跑起一个小项目。
学习要点
  • 线代：矩阵、特征值、向量空间，ML 的底层语言。
  • 概率：分布、贝叶斯、期望方差，理解模型不确定性。
  • 微积分：梯度与链式法则，反向传播的基础。
  • 配合 3Blue1Brown 直观视频，先懂再算。
学习要点
  • 关系模型、SQL 增删改查、ER 图与范式。
  • 配合 ima 知识库里的三级笔记，边学边存。
  • 当前优先级最高：先保 9 月考试。
L2 · 核心能力
学习要点
  • 数组 / 链表 / 栈 / 队列 / 树 / 图 / 哈希。
  • 排序、二分、DFS/BFS、动态规划入门。
  • 每周 3 题，错一题就当天弄懂。
学习要点
  • 监督 / 无监督学习、训练-验证-测试流程。
  • 评估指标：准确率、召回、F1、ROC。
  • 用 Sklearn 跑通第一个分类器。
学习要点
  • 常用命令、权限、管道、ssh 远程连服务器。
  • git 工作流：commit / branch / rebase / PR。
  • 用 conda 或 venv 管理 Python 环境。
L3 · 专项深入
学习要点
  • 张量、autograd、nn.Module 搭建网络。
  • CNN 做图像，Transformer 做序列。
  • 从零手写一个网络，理解每一行在算什么。
学习要点
  • 用 SQL + Python 清洗一份真实实验数据。
  • pandas 管道：缺失值、归一化、特征构造。
  • 产出可视化图表，直接复用进实验室汇报。
学习要点
  • 前端 + 云函数，把熵减做成可演示的小程序。
  • 接口设计、数据库读写、上线部署。
  • 学会把零散脚本包装成产品。
L4 · 方向产出
学习要点
  • OpenCV 预处理，YOLO 做目标检测。
  • 用实验室器材或校园场景训一个 demo。
  • 把检测框接进熵减小程序做展示。
学习要点
  • 熵减参赛，把减碳平台做成完整作品。
  • 复现实验室电极材料数据，冲论文 / 奖项。
  • 竞赛逼出交付质量，比自学快。
学习要点
  • 每个项目写 README、录 demo、放链接。
  • 用这个网站当作品集中枢。
  • 面试时直接打开讲，不靠口头描述。
L5 · 终点
学习要点
  • 以就业前景为第一优先级做抉择。
  • 凝聚态偏基础科研，光学工程偏产业应用。
  • 408 数据结构与主线刷题记录共用。
学习要点
  • 简历突出项目与数据，不堆课程名。
  • 盯暑期实习与校招提前批。
  • 作品集链接放显眼位置。
学习要点
  • 基础八股 + 现场手撕代码。
  • 用模拟面试沉淀回答模板。
  • 把 L6 刷题记录转为面试弹药。
