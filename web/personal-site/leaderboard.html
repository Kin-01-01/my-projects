GITHUB WEEKLY · 自动榜单

GitHub 每周热门项目榜单

由 GitHub Actions 每周自动采集，展示指定主题下 star 增长最快的开源项目。数据在服务端预拉取后写入静态文件，网页直接读取渲染，稳定不受 GitHub API 限流影响。

01

定时触发

每周一 00:00 UTC（北京时间周一 08:00），GitHub Actions 自动运行采集脚本，亦支持手动触发。

02

API 拉取

调用 GitHub Search API，按 sort=stars 拉取指定主题（如 machine-learning）下 star 最高的前 N 个项目。

03

变化计算

逐仓库对比上周快照的 star 数，得出 NEW / ▲上升 / ▼下降 / -持平 的周变化，便于跨周对比。

04

落库与展示

整份快照写入 leaderboard-data.json 并提交。本页读取后渲染卡片，刷新即最新。
