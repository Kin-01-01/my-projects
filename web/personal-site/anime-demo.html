用动效讲好故事

基于 anime.js v4 构建的动效实验室。一个 animate() 驱动 CSS、SVG、时间线与滚动编排。

Capabilities

四大核心能力

滚动到这里，卡片会以错峰（stagger）方式依次浮现。再往下看 SVG 描边与时间线编排。

S

Stagger 错峰

一行 delay: stagger(90) 让元素从中间或两端依次入场，无需手写延迟。

T

Timeline 编排

createTimeline 把多个动画按时间轴精确串起来，支持相对偏移与重叠。

V

SVG 描边

用 pathLength=1 归一化路径，animate strokeDashoffset 即可画出任意形状。

R

滚动触发

IntersectionObserver 进入视口即播放，把动效绑在用户视线节奏上。

SVG Draw

线条自己会画

滚动进入视口时触发描边动画。点按钮可重播。

Timeline

时间线编排

点播放，一排色块按时间轴依次缩放浮现，最后整体回落。

Source

关键代码片段

V4 用命名导入，ease 取代 easing，stagger 是内置工具函数。

// ESM CDN 引入（无需打包）
import { animate, stagger, createTimeline }
  from 'https://cdn.jsdelivr.net/npm/animejs/+esm';

// 卡片错峰入场
animate('.feat-card', {
  opacity: [0, 1], translateY: [40, 0],
  scale: [.96, 1], duration: 600,
  delay: stagger(90), ease: 'outExpo',
});

// SVG 描边（pathLength=1 归一化）
animate('.draw', { strokeDashoffset: [1, 0],
  duration: 1600, ease: 'inOutQuart' });

// 时间线编排
const tl = createTimeline({ defaults: { ease: 'outExpo' } });
tl.add('.tl-bar', { opacity: [0,1], scale: [.4,1],
     duration: 500, delay: stagger(80) })
  .add('.tl-bar', { y: -14, duration: 400,
     delay: stagger(60) }, '-=200');
