## __四、统一测算方法学：排放因子法__

平台所有核算遵循：

E = Σ ( ADᵢ × EFᵢ )

- \`E\`：温室气体排放总量（kgCO₂e）；
- \`ADᵢ\`：第 i 项活动水平（如用电量 kWh、通勤距离 km、餐数）；
- \`EFᵢ\`：对应的排放因子（来自第三节）。

核算结果按"范围一 / 二 / 三"与"出行 / 餐饮 / 用能 / 资源 / 垃圾"分类聚合，并在界面回显公式 \`AD × EF = E\`，做到可解释、可核查。

## __五、第三层：校区级活动水平与年排放的测算__

### __5.1 校区年排放总量（模拟，标注假设）__

某校区年排放 __E\_校区 ≈ 13,902 tCO₂e__ 为基于"建筑面积 \+ 功能类型 \+ 标准因子"的工程估算（非实测），拆分如下：

| 范围 | 年排放 (tCO₂e) | 拆分项 |
| --- | --- | --- |
| 范围二 | 12,678.3 | 外购电力 3,053.3 + 集中供热 9,625.0 |
| 范围三 | 966.1 | 师生通勤 800.0 + 垃圾处理 150.0 + 自来水 16.1 |
| 范围一 | 257.6 | 食堂燃气 207.6 + 公务车燃油 50.0 |

数值取整与分配为演示用测算，接入楼栋级能耗计量后自动校准。

### __5.2 场景占比（模拟，标注假设）__

按场景分摊（基于建筑面积与功能类型权重）：

| 场景 | 占比 | 年排放 (tCO₂e) |
| --- | --- | --- |
| 供暖 | 38% | 5,282.8 |
| 实验室 | 22% | 3,058.4 |
| 宿舍 | 19% | 2,641.4 |
| 食堂 | 11% | 1,529.2 |
| 出行 | 10% | 1,390.2 |

### __5.3 逐日序列生成方法（模拟）__

日排放序列由 \`campusSeries()\` 基于年总量按 300 个在校日折算为日基准，再叠加三类系数（用于体现真实规律，非随机噪声）：

- __周末系数__：周末 ×0.72（实验室 / 教学回落）；
- __采暖季系数__：供暖场景在采暖期内按月份 ×0.6–1.0（隆冬最高）；
- __确定性噪声__：\`±10%\`，由日期字符串哈希（\`hashSeed\`）生成，__保证同一天多次打开结果完全一致__（评审演示可复现）。

所有派生数值在界面标注为"测算值"，不冒充实测。

### __5.4 楼宇排行生成方法（模拟）__

\`buildingRank()\` 依据各楼栋"基准权重 × 校区日总量 × 场景占比"测算日均排放（kg），按权重排序取前 8；权重基于楼栋功能（如实验楼一、实验楼二实验室权重高）。楼名为真实数据，数值为基于面积的测算值，备注"接入校园能耗计量后自动替换为实测值"。

## __六、学生打卡（个人级）核算方法__

学生每次打卡提交一组 \`\{因子ID, 活动量\}\`，由 \`calcBatch()\` 逐项核算并汇总：

单日排放 = Σ ( 各活动量 × 对应因子 )

示例（全堂低碳日预设）：步行 2km（0）× 0.6361 \+ 素食 3 餐 × 0.6 \+ 用电 1.0 kWh × 0.6361 \+ 打印 0 张 ≈ __2.44 kgCO₂e__，与界面"低碳日 ≈ 2.6 kg"提示一致。

__个人日基线 DAILY\_BASELINE = 2.4 kgCO₂e / 人·天__：取自"低碳日—普通日"区间中值，作为对标与缺卡赋值基准。

## __七、未打卡自动赋值规则（防刷榜）__

为保证排行榜公平、避免"不打卡 = 零排放"刷榜，定义缺卡自动赋值：

autoEmission = DAILY\_BASELINE × (1 \+ 0.3 × m)，封顶 2 × DAILY\_BASELINE

- \`m\`：统计周期内连续缺卡天数；
- 缺卡越多，赋值越接近封顶 4.8 kg（高于基线，体现"不记录 ≠ 无排放"）；
- 标记 \`reporter=system / auto=true\`，__不计入打卡活跃榜__；
- 仅用于个人 / 院系人均榜的对标值，不影响活跃榜排名。

## __八、排行榜聚合方法__

三榜均由 \`demoRank()\`（云函数 \`getRankings\` 就绪前的前端兜底，逻辑一致）计算：

1. 取候选样本，按打卡率折算缺卡天数，缺卡日套用第七节自动赋值；
2. 计算每人 / 每组"人均日排放 = 周期总排放 ÷ 周期天数"；
3. __人均日排放越低越靠前__（减碳先锋榜）；
4. 院系 / 楼宇榜按分组聚合成员人均；
5. 隐私档 \`private\` 不进公开榜，\`fuzzy\` 展示脱敏昵称与区间值。

虚拟样本（30 人）由 \`virtualStudents()\` 用 __xmur3 \+ mulberry32 确定性伪随机__生成，日均 0.9–3.8 kg、打卡率 70%–100% 双侧分布，保证榜单区分度且__多次刷新结果一致__（评审可复现）。

院系 / 宿舍人均榜按 \`user\_profile.college\` 分组聚合，覆盖某校区全部 __12 个院系__（基础医学院、医学检验学院、中医学院、药学院、临床医学院、理学院、法政学院、文学院、马克思主义学院、公共体育部、国际教育学院、研究生学院），分组口径与上述第一层参数一致；"我的"页院系下拉同样取自此名单，确保前台选择、排行榜分组、种子数据三方一致。

## __九、AI 减碳建议的方法__

- __数据输入__：取用户近 7 天打卡记录，拆平为条目级 \`\{因子ID, 活动量, 排放Kg\}\`；
- __大模型路径__：构造结构化 Prompt（要求"建议 \+ 预计减碳量 \+ 核算依据"），调用大模型流式生成；任一环节失败自动回落；
- __规则引擎兜底 \`ruleSuggest\`__：基于分类占比（出行 > 30%、荤食 ≥ 3 餐、空调 > 20h、纸杯 > 5 个）生成可解释建议，每条带回显公式（如"私家车 10km × (0.234 − 0.0338) = 2.00 kgCO₂e"）；
- __即时建议 \`instantTip\`__：取最近一次打卡记录，调 \`ruleSuggest\` 返回首条，打完卡立显，把建议落到具体行为。

5. 新闻 / 题库接入 \`getNews\` 真实 API 后，替换种子内容即可。
