Blender 5.3.0 / Eevee 卡通三渲二重建工程。

## 空间布局

- 房屋沿 X 轴布局，室内严格从左到右：**卧室 → 厨房 → 卫生间**
- 卧室：绿色旧沙发、木桌、木床、衣柜、CRT 电视、暖炉、弓箭、挂画、草帽、蜘蛛网、春字窗花、窗边玉米、背包、散落鞋子
- 厨房：浅绿色双开门冰箱、灶台、炒锅/汤锅、木餐桌+两把椅子、水壶、瓶罐、菜筐、墙面辣椒大蒜
- 卫生间：独立隔间、洗手池+镜子、水桶、木桌、编织篮、扫帚拖把、毛巾、拖鞋
- 外部：紫褐/玫红破损木瓦斜屋顶、苔藓、烟囱与电视天线、宽木平台与长台阶、门廊长凳、X 形栏杆、双灯柱、右侧披屋、破旧栅栏、蓝色皮卡、原木堆、轮胎堆、木桶、柴棚、树桩、陶罐、屋檐干玉米/辣椒/大蒜
- 环境：狗熊岭针叶林（中景树墙 + 远景大树）、草地、泥土小径、短草、石块与野花

## 工程规范

- **拓扑**：34,460 面，100% 四边面；非四边面 0；退化面 0
- **对象**：2,015 个独立网格 + 109 个分组空物体 + 4 相机 + 13 灯光（共 2,141 个对象），全部可编辑；无修改器
- **UV**：2,015/2,015 个网格均有 UV 展开
- **材质**：UV 驱动的程序化手绘卡通 PBR（Eevee Shader-to-RGB 三段色阶 + 噪声木纹/磨损/凹凸），无外挂贴图；Standard 色彩管理，4K 输出
- **渲染**：Eevee / 64 采样 / Standard Medium High Contrast / 3840×2880

## 剖切结构

屋顶与近侧墙体分别放在独立集合中：

- `Roof`：屋顶 + 木瓦 + 烟囱
- `House_Cutaway_Near`：正面墙、门、前窗、右侧外墙、门廊立柱、屋檐挂物

隐藏这两个集合即可得到完整剖切；它们是工程的一部分，不是删除。工程默认保存为剖切状态：`Roof` 与 `House_Cutaway_Near` 已隐藏，当前相机为 `CAM_IsometricCutaway`。要查看完整外景，在 Outliner 中重新开启这两个集合，并切换到 `CAM_Exterior`。

## 重新生成

```bash
blender --background --factory-startup --python build_cabin.py
blender --background Guangqiang_Cabin.blend --python render_final.py
```

适用 Blender 5.3+。构建脚本使用纯 bpy/bmesh，无第三方依赖。

## 说明

这次在参考图基础上重做屋顶与正立面的视觉重心：大块紫褐木瓦、苔藓、红漆门窗、白窗帘、原木叠层、门廊栏杆/长凳/台阶灯和右侧披屋。材质采用程序化手绘卡通 PBR，强调固有色、木纹/污渍和柔和天光；如果要替换成外挂 4K PBR 贴图，现有 UV 已全部展开，可直接接入。
