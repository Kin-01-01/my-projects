# 《熊出没》光头强的小木屋 · 工程清单

工程文件：`Guangqiang_Cabin.blend`（Blender 5.3.0 / Eevee）
成图目录：`renders/`（4 张，3840 × 2880）

## 交付概览
- 对象总数：2141（网格 2015 / 分组空物体 109 / 相机 4 / 灯光 13）
- 面数：34,460
- 拓扑：100% 四边面；非四边面 0；退化面 0
- UV：2015/2015 网格已展开
- 修改器：0（全部为可编辑原始网格）
- 剖切控制：`Roof` + `House_Cutaway_Near` 默认隐藏（剖切状态）；工程内保留完整屋顶、正面墙与右侧墙，可随时开启
- 室内顺序（X 轴从左到右）：卧室 → 厨房 → 卫生间
- 渲染：Eevee / Standard Medium High Contrast / 64 samples / 3840×2880
- 材质：UV 驱动的程序化手绘卡通 PBR；无外挂贴图，现有 UV 可直接接 4K PBR 贴图

- `Guangqiang_Cabin.blend` — 可编辑工程
