# 设计 spec · 高中物理录课课件《平抛运动》

> 三套逻辑的唯一共同输入。三版同内容、同尺寸，只换设计逻辑。

## 1. 项目是什么

一份**师范生微格教学（试讲）用的高中物理录课课件**。使用者（河北北方学院 物理师范专业 大二学生）要站在镜头前讲一节 10 分钟片段，课件是背后的视觉支撑——录屏时它占满画面，同时要撑得住「教学环节清晰、像真老师做的」这一层隐性评审标准。

不是科普视频，不是纯讲义。是**教学演示**：要能看出导入→探究→建模→规律→应用的节奏。

## 2. 受众与使用场景

- **直接受众**：高中学生（听课者），需要在 1m 笔记本 / 10m 投屏两种距离下都能读
- **间接受众（真正的评审者）**：微格教学的指导教师与同学——他们在判断「这个人会不会上课」
- **场景**：录课 / 试讲。画面 16:9，可能录屏、可能投屏
- 因此：**教学环节的可见性** 与 **板演/推导的清晰呈现** 是硬需求，不能只顾好看

## 3. 核心内容与内容要点（真实物理内容，禁止编造）

**课题**：平抛运动（高中物理 必修二 · 曲线运动）

**真实物理事实（三版必须一致，不得改数值）**：
- 定义：将物体以一定的初速度沿**水平方向**抛出，物体只在**重力**作用下所做的运动
- 条件：(1) 初速度水平 (2) 只受重力（忽略空气阻力）
- 处理方法：**运动的合成与分解**——化曲为直
  - 水平方向：不受力，匀速直线运动。`x = v₀t`，`v_x = v₀`
  - 竖直方向：只受重力，初速为零的自由落体。`y = ½gt²`，`v_y = gt`
- 轨迹方程：消去 t 得 `y = g/(2v₀²) · x²` → **抛物线**
- 落地时间：`t = √(2h/g)`，**只由抛出高度 h 决定，与初速度 v₀ 无关**
- **关键演示实验**：平抛小球与自由落体小球从同一高度同时释放 → **同时落地**（平抛的竖直分运动就是自由落体）
- 常量：`g = 9.8 m/s²`
- 示例数据（可算核对）：`v₀ = 10 m/s`，`h = 20 m` → `t = √(2×20/9.8) ≈ 2.0 s`，水平射程 `x = 10 × 2.0 = 20 m`

**教学环节骨架**（课件要能体现其中至少 3 个环节）：
1. 情境导入（飞机投弹 / 水平投出的球，为什么走曲线？）
2. 观察与猜想（频闪照片：水平等间距、竖直间距增大）
3. 建模与分解（水平匀速 + 竖直自由落体）
4. 规律与公式（x / y / 轨迹方程 / 落地时间只由 h 决定）
5. 应用（示例数据求解）
6. 小结

## 4. 情感基调与气质关键词

- **清晰 > 炫**：物理课件的第一美德是可读性，推导关系一眼看懂
- **有教学感**：像一位懂教学的老师做的，不像设计师炫技，也不像 AI 模板
- **安静的自信**：不吵闹、不过度装饰；但关键处（比如「时间只由高度决定」这个反直觉结论）要有视觉重量
- **反 AI slop**：禁止紫渐变、emoji 图标、圆角卡片+左彩色 border、GitHub-dark 均匀深蓝底+霓虹 glow

## 5. 输出格式与尺寸（三版必须统一）

- **尺寸：1920×1080**（16:9）
- **每方向 2 页代表页**（兼作后续完整 deck 的 showcase）
  - 第 1 页：**课题页 / 情境导入**（课题名 + 一个能引发疑问的情境）
  - 第 2 页：**核心概念页**（运动的合成与分解 + 平抛轨迹与分运动的**动画演示**）
- **交付形态**：单个 HTML 文件（`file://` 双击可开），内含 2 个 `<section>`，支持键盘 ←/→ 翻页；不依赖任何 CDN 与构建
- **动画必须真实可见**：第 2 页的小球平抛 + 水平/竖直分运动对比必须动起来（CSS animation 或 requestAnimationFrame，自动循环，无需点击）
- **字体**：中文优先本地字体栈（思源黑体/思源宋体/苹方/微软雅黑），拉丁可指定开源字体但**必须有系统 fallback**；版式不得依赖外部字体加载（禁止 Google Fonts 阻塞 —— 国内环境可能加载失败导致版式崩）

## 6. 已知约束

- 无品牌资产（不是某个机构的官方物料），不找 logo
- 图片不是内容必需：物理图示（轨迹、矢量、频闪点）**用 SVG / CSS 精确绘制**，不要找 stock 照片，不要用 CSS 色块糊弄
- 全文中文，物理量用斜体拉丁字母（v₀、g、t、x、y），单位用正体（m/s、m/s²）
- 中文引号用「」不用 ""
- **可读性硬底线**：正文 ≥14px（1920 宽下建议 ≥28px），注释 ≥12px（建议 ≥20px），正文对比度 ≥4.5:1
- 留白必须是构图（有明确视觉锚点），不能是内容缺席

## 7. 视觉母题假设（form 从内容长出来的种子）

这个课题独有的、别的课题不会有的视觉结构：
- **抛物线轨迹本身**——它是内容的主体，也是构图的主线
- **分解的「十字」**——水平匀速与竖直自由落体两条正交时间轴，构成全课的结构母题
- **同时性**——平抛球与自由落体球在同一时刻的等高关系（频闪照片的等时点）

三版各取其中一个作为自己 form 的种子，写进交付说明「form 来自内容的哪里」。

## 8. 三版差异要求（防换皮）

**三版的布局骨架必须互异**：导航/构图/内容区结构至少一项结构性不同。不许两版共用同一骨架只换色换字体。
