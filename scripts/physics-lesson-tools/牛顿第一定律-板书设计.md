# 牛顿第一定律 · 板书设计

> 配套课件：`pptx-out/牛顿第一定律-试讲课件-可编辑.pptx`（14 页）
> 设计目标：主板保留主线（历史脉络 + 第一定律 + 惯性），副板随讲随擦；红笔标定律原文与「质量是惯性量度」。

---

## 一、版面分区

```
┌──────────────────────────────────────────┬────────────────────┐
│             牛顿第一定律（标题）             │                    │
├──────────────────────────────────────────┤   副板书（可擦）    │
│              主板书（全程保留）             │  · 伽利略理想实验  │
│  一、历史脉络（认识过程）                   │  · 惯性现象辨析    │
│    亚里士多德：力维持运动（×）              │  · 例题选择        │
│    伽利略：理想实验 → 不需力维持            │                    │
│    笛卡尔：不受力沿直线运动                │                    │
│    牛顿：总结为第一定律                    │                    │
│  二、牛顿第一定律（惯性定律）【红笔】       │                    │
│    一切物体总保持匀速直线运动               │                    │
│    或静止，直到外力迫使它改变               │                    │
│  三、惯性【红笔】                          │                    │
│    一切物体都有惯性（固有属性）             │                    │
│    质量是惯性大小的唯一量度                │                    │
└──────────────────────────────────────────┴────────────────────┘
```

- **主板**（左，约 2/3 宽）：历史脉络、第一定律原文、惯性。全程不擦。
- **副板**（右，约 1/3 宽，虚线框）：理想实验草图、惯性现象辨析、例题。讲完即擦。

---

## 二、书写顺序（5 步，不回头擦主板）

1. **引入（P1–P2）**：先不写，举"推桌 / 骑车"现象提问。
2. **历史脉络（P3–P6）**：副板画斜面实验草图；主板写四人观点，亚里士多德处红笔圈 `×`。
3. **第一定律（P7–P8）**：主板写定律原文（红笔整段）。
4. **惯性（P9–P10）**：主板写"惯性 + 质量是惯性唯一量度"（红笔）。
5. **辨析 + 小结（P11–P13）**：副板辨析/例题，最后指主板回顾。

---

## 三、时间节奏（45 分钟 / 14 页）

| 时段 | 页码 | 板面动作 |
|------|------|----------|
| 0–5 min | P1–P2 | 空白，现象提问 |
| 5–12 | P3 | 主板：亚里士多德（×） |
| 12–22 | P4–P6 | 副板：理想实验；主板：伽利略/笛卡尔/牛顿 |
| 22–32 | P7–P8 | 主板：第一定律原文（红笔，重点） |
| 32–40 | P9–P10 | 主板：惯性 + 质量 |
| 40–44 | P11–P12 | 副板：辨析 / 例题，讲完即擦 |
| 44–45 | P13–P14 | 指主板小结；角落写作业 |

## 四、逐页板书脚本

- **P1 封面**：黑板空白，开场问候。
- **P2 引入**：空白；口述"推桌、骑车"，提问"运动靠力维持吗？"。
- **P3 亚里士多德**：主板写「亚里士多德：力是维持运动的原因」，红笔圈 `×`。
- **P4 伽利略质疑**：副板画斜面 + 小球草图。
- **P5 理想实验推理**：副板写「摩擦↓→上升等高；无摩擦→永远运动」。
- **P6 笛卡尔补充**：主板写「笛卡尔：不受力时沿直线运动」。
- **P7 牛顿总结**：主板写「牛顿：总结为第一定律」→ 接写「二、牛顿第一定律」原文（红笔）。
- **P8 定律解读**：口头讲关键词（一切 / 总保持 / 外力），不写新字。
- **P9 惯性概念**：主板写「三、惯性：一切物体都有惯性（固有属性）」（红笔）。
- **P10 质量与惯性**：主板写「质量是惯性大小的唯一量度」（红笔）。
- **P11 惯性现象辨析**：副板画"车停人前倾"，先让学生说，再点按钮揭晓。
- **P12 例题选择**：副板写题干与选项，答案点按钮揭晓，不提前写。
- **P13 小结**：手指主板二、三，口头回顾，不写新内容。
- **P14 作业**：右下角写"作业：练习册 P__ 第__题"。

---

## 五、试讲加分细节

- 定律原文用**红笔整段写**，是评分核心，全程保留——评委一眼看到主线。
- 伽利略**理想实验**是难点，副板画斜面 + 小球，边画边讲"减小摩擦"的推理链条。
- 亚里士多德处标 `×`，体现"历史纠错"主线，比平铺直叙更显功底。
- 惯性现象（P11）与例题（P12）都让学生**先口答**，再点按钮揭晓，板书只写题干不写答案。
- 写板时**侧身半转**，别背对学生；每写完一句停 1–2 秒让评委记录。
