# 《牛顿第一定律》微课版 v4 · 板书设计

> 依据：`牛顿第一定律-微课版-v4.pptx`（18 页，15 分钟微课）
> 本课与常规试讲版的关键差别：**主线是「理想斜面 + 合理外推」**，不是「毛巾/棉布/木板」。
> 所以板书的图形是**双斜面 + 小球**，不是小车在三种表面上滑。别画错。

---

## 一、板面分区

黑板分三块：

| 区域 | 占宽 | 内容 | 保留 |
|---|---|---|---|
| **主板（左 2/3）** | 约 66% | 课题、核心问题、科学史接力、理想斜面四步、定律原文、惯性 | **全程不擦** |
| **副板（右 1/3）** | 约 34% | 生活例子、判断表、四步法演算、变式训练 | 讲完即擦 |
| **角落（右下）** | — | 作业 | 最后写 |

**为什么这样分**：评委一眼扫过去，主板上必须能看见「问题 → 实验 → 推理 → 定律 → 概念」这条完整链条。副板只放"用完就不需要"的推导和例题，避免抢视线。

## 二、主板终稿长这样（讲完 P11 时的样子）

```
┌────────────────────────────────────────────┬──────────────┐
│  牛顿第一定律（惯性定律）                   │ 生 活 中 的   │
│                                            │ 惯 性         │
│  核心问题：力是维持运动，还是改变运动？      │ ①急刹车前倾   │
│                                            │ ②拍打除尘     │
│  科学史接力                                 │ ③跳远助跑     │
│  亚里士多德 ✗ 力是维持运动的原因（经验思辨） │ ④锤头撞柄     │
│  伽利略     ✓ 运动不需要力维持（实验+推理）  │（讲完擦掉）   │
│  笛卡尔     → 补充：方向也不变              │              │
│  牛顿       → 统一成一条定律                │              │
│                                            │              │
│  理想斜面 · 四步                            │              │
│  ① 事实：滚下→滚上，几乎到原高度（略低＝摩擦）│              │
│  ② 推论：无摩擦→到达原高度                  │              │
│  ③ 推论：减小倾角→仍到原高度，路程更长       │              │
│  ④ 推论：倾角→0 → 永远匀速直线运动           │              │
│      只有 ① 是实验，②③④ 都是合理外推      │              │
│                                            │              │
│  ★ 一切物体在没有受到力的作用时，           │              │
│    总保持静止状态或匀速直线运动状态。        │              │
│                                            │              │
│  ★ 力不是维持运动的原因，                   │              │
│    而是改变运动状态的原因。                  │              │
│                                            │              │
│  ★ 惯性：只与质量有关，与速度、受力无关     │              │
└────────────────────────────────────────────┴──────────────┘
```

★ ＝ 红粉笔。这三句必须红，评委看一眼就知道重点在哪。

## 三、主板图形怎么画（P6 就画，一直用到 P8）

在主板中间偏右画一组**递减倾角的双斜面**，一条比一条平：

```
      A            B             C              D
   ＼    ／      ＼      ／     ＼        ／
    ＼  ／        ＼    ／       ＼      ／
     ＼／          ＼  ／         ＼    ／      ───────────→
   ──────        ──────────    ──────────────   永远运动
  路程短         路程较长        路程更长        速度不变
```

- 左坡（释放坡）**四条一样**，只改右坡倾角 —— 这是控制变量，画的时候要说一句。
- 每条都要标**释放高度 h** 和**上升高度 h′**，让学生看见"高度不变、路程变长"。
- P8 讲完，在 D 那条下面补一行：`倾角→0，永远匀速直线运动`。

## 四、书写顺序（6 步，全程不回头擦主板）

| 步 | 时机 | 写什么 |
|---|---|---|
| 1 | P1 封面 | 主板顶部：课题 + **核心问题**（力是维持还是改变）。写完停 3 秒，不回答 |
| 2 | P4–P5 科学史 | 主板：亚里士多德 ✗ → 伽利略 ✓ → 笛卡尔 → 牛顿，四行对齐写 |
| 3 | P6 装置与事实 | 主板画**双斜面图** + 写①可靠事实（略低＝摩擦） |
| 4 | P7 四步 | 主板写 ②③④ 三条推论，末尾红笔圈注"只有①是实验" |
| 5 | P9–P10 定律 | 主板**红笔**写定律原文 → 下面红笔写"力是改变……的原因" |
| 6 | P11 惯性 | 主板**红笔**写"惯性 · 只与质量有关"；副板写四个生活例子 |

P12 之后**主板不再动**，只动副板；P16/P17 是"指主板回顾"，不是"补主板"。

## 七、加分细节

1. **红笔只用在三处**：定律原文、"力是改变运动状态的原因"、"惯性只与质量有关"。别到处红，红多了就不叫重点了。
2. **亚里士多德后面画 ✗**，伽利略后面画 ✓ —— 一个符号把两千年争论讲清楚，比写两行字强。
3. **双斜面图是这课的命根子**：四条右坡倾角递减必须画得**一眼看出在变平**，否则"合理外推"讲不生动。
4. **擦副板的时机**：P15 变式讲完立刻擦，让最后两分钟视线只剩主板 —— 评委看到的是一条干净的结论链。
5. **写板时侧身半转**，别背对学生；每写完一句停 1–2 秒让评委记录。
6. **P9 是全课最慢的一页**：定律原文边写边读，四个关键词逐个停，这里是评委打分钉死的地方。
7. **别在主板写例题**：四步法演算只在副板走一遍，主板被污染就散了。
8. 微课是无生试讲，**停顿要夸张一点**——备注里标了 3 秒的地方，真的数三下，镜头前才不显得赶。

## 八、一句话自检

讲完后黑板应该是：**左边一条从"亚里士多德"走到"惯性"的完整链条，右边干干净净只剩作业**。
如果主板上还留着例题演算或变式训练，说明该擦的没擦。
