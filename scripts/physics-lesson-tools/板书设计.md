# 平抛运动 · 板书设计

> 配套课件：`pptx-out/平抛运动-试讲课件-可编辑.pptx`（14 页）
> 设计目标：主板保留主线、副板随讲随擦；核心公式用红粉笔标出；全程约 45 分钟。

---

## 一、版面分区

```
┌──────────────────────────────────────────┬────────────────────┐
│              平抛运动（标题）               │                    │
├──────────────────────────────────────────┤   副板书（可擦）    │
│              主板书（全程保留）             │  · 化曲为直        │
│  一、定义：水平抛出、仅受重力的运动          │  · 例题演算        │
│  二、条件：v₀ 水平≠0；只受重力              │    列式→代入→结果  │
│  三、性质：匀变速曲线运动，a = g ↓          │                    │
│  四、规律（核心·红笔）                      │                    │
│    水平：x=v₀t ， vₓ=v₀                    │                    │
│    竖直：y=½gt² ， v_y=gt                   │                    │
│    合速度：v=√(v₀²+v_y²)  tanθ=v_y/v₀      │                    │
│    轨迹：y=gx²/(2v₀²)（抛物线）            │                    │
│    速度变化：Δv=gΔt（竖直向下）            │                    │
└──────────────────────────────────────────┴────────────────────┘
```

- **主板**（左，约 2/3 宽）：定义、条件、性质、规律。全程不擦。
- **副板**（右，约 1/3 宽，虚线框）：研究方法、例题演算。讲完即擦，保持清爽。

---

## 二、书写顺序（5 步，不回头擦主板）

1. **引入（P1–P2）**：先不写，留白制造悬念，口述"飞机投弹 / 水平抛小球"。
2. **定义与条件（P3）**：写主板「一、二」。
3. **研究方法（P4–P5）**：写副板「化曲为直 · 运动的合成与分解」。
4. **规律推导（P6–P10）**：写主板「三、四」全部公式，红笔标 `核心`。
5. **例题 + 小结（P11–P13）**：副板演算两题（讲完擦）；最后指主板回顾。

## 四、逐页板书脚本

- **P1 封面**：黑板空白，开场问候。
- **P2 情境引入**：空白；口述现象，提问"小球为什么这样落？"。
- **P3 定义与条件**：写主板「一、定义 / 二、条件」。
- **P4 研究方法**：副板写「方法：化曲为直」。
- **P5 合成与分解**：副板补「水平匀速 + 竖直自由落体」。
- **P6 水平方向**：主板写「四·水平：x=v₀t，vₓ=v₀」。
- **P7 竖直方向**：主板写「四·竖直：y=½gt²，v_y=gt」。
- **P8 合速度**：主板写「四·合速度：v=√(v₀²+v_y²)，tanθ=v_y/v₀」。
- **P9 轨迹**：主板写「四·轨迹：y=gx²/(2v₀²)（抛物线）」；右下角画抛物线草图。
- **P10 速度变化**：主板写「四·Δv=gΔt（竖直向下）」，红笔标。
- **P11 例题1（v₁/v₂/Δv）**：副板演算，讲完擦。
- **P12 例题2（落地时间）**：副板演算 t=√(2h/g)，讲完擦。
- **P13 小结**：手指标题与主板四，口头回顾，不写新内容。
- **P14 作业**：右下角写"作业：练习册 P__ 第__题"。

---

## 五、试讲加分细节

- 主板公式用**红粉笔**写核心（`v=√…`、`Δv=gΔt`），全程保留——评委一眼看到主线。
- 副板只放「推导中间式 + 例题列式」，讲完擦掉，避免与主板抢视线。
- 轨迹抛物线画在主板右下角，配合 P11 速度矢量的 `Δv` 讲解。
- 写板时**侧身半转**，别背对学生；每写完一句停 1–2 秒让评委记录。
- 点击显示答案的页面（P11/P12）：先让学生口答，再点按钮揭晓，板书只写演算、不提前写答案。
