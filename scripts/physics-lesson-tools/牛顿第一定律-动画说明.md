# 《牛顿第一定律》课件 · 动画说明

> 对象：`牛顿第一定律-浅绿主题版-A.pptx`（14 页 / 1920×1080）
> 动画全部由本机 PowerPoint 自身生成（原生 OOXML），**无外部依赖、无宏、无外链**，
> 在 Windows / macOS / WPS / 移动版 PowerPoint 上均可正常播放。

---

## 一、全局参数（每页一致）

| 项目 | 设定 | 说明 |
|---|---|---|
| 页面切换过渡 | **淡出 Fade，0.7 s** | 全 14 页统一，与浅绿扁平风格一致；不抢内容 |
| 自动入场 | **淡入 Fade，0.5 s** | 页眉、标题、页脚、静态框架等 |
| 自动入场错峰 | **90 ms / 件，封顶 0.8 s** | 进页后 0.8 s 内全部就位，不会「一片片慢慢冒」 |
| 点击触发 | **1 次点击 = 1 个教学推进点** | 讲师说完一句点一次，节奏由讲课人掌握 |
| 组内跟随 | 与上一动画**同时**，再错峰 80 ms | 同一组的多件元素（如「行 + 数据条」）一起给出 |
| 文字类效果 | 淡入 0.5–0.6 s | 克制、不干扰阅读 |
| 图形/数据类效果 | 擦出 Wipe 0.7–1.0 s | 读作「展开 / 生长」，用于轨道与数据条 |

**不使用**：动作路径、媒体/音频、触发宏、超链接式跳转 —— 这几类最容易在跨平台播放时失效。

## 三、三处「实验类动画」的设计意图

**P5 · 实验步骤的逐步展示**
先让装置自动就位（斜面 + 小车在坡顶），再点出「怎么做」（器材/原理/步骤/数据），
然后三种水平面 毛巾 → 棉布 → 木板 逐条擦出 —— 对应「只改变表面粗糙程度」这个变量。
控制变量条最后单独点击弹出，作为本页落点。

**P6 · 数据变化的过程演示**
点一行，表格文字与该行对应的「滑行距离条」**同时**出现：毛巾（深绿、最短）→ 棉布（中）→ 木板（最长）。
三条条子长度递增，观众不用读数字就能看出「越光滑滑得越远」。结论条第 4 次点击给出。

**P7 · 原理动态示意**
四条轨道按 毛巾 → 棉布 → 木板 → 绝对光滑 逐条擦出，长度依次递增；
最后一条是**虚线**，擦出时长 1.0 s（比前面慢），读作「一路延伸、永不停下」，
文字「速度不变 → 永远运动下去」随后落位 —— 这就是本课的理想实验法推理链。

## 四、放映与兼容说明

- **用「幻灯片放映」播放**，不要只看编辑视图或预览窗口（编辑视图不展示动画）。
- 每页第一次点击前，页面已显示标题与静态框架；每次点击推进一个教学点，点多了就进入下一页的过渡。
- **答案页（P12）**：题目面板先显示，「答案：C」初始隐藏 —— 先让学生口答，再点击揭晓。
- **跨设备**：所有效果均为 PowerPoint 原生类型（淡入 10 / 擦出 22 / 淡出切换 1793），
  不含动作路径与多媒体，Office 365 / 2016+ / WPS 均可播放。
- 若在 WPS 中个别「擦出」方向与 PowerPoint 略有差异（不同版本对默认方向的处理不同），
  观感仍是「逐步展开」，不影响理解。
- 母版级「淡出切换」若被现场模板覆盖，可在「切换 → 计时」里把持续时间改回 0.7 s。
- 逐页讲解要点、过渡语、核心结论都已写入**演讲者备注**，放映时用「演示者视图」查看。
