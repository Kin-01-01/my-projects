# 检索与调度日志 · 亚稳相固态电解质综述

> 全流程依据调研大纲 v2 与 6 项防幻觉硬约束执行。所有纳入文献均经 Crossref API 逐条核验 DOI；未核验/无权威来源的文献一律未收录。

## 1. 检索平台与工具
- **Crossref REST API**（`api.crossref.org/works`）：主检索与 100% 元数据核验通道（已验证可达）。
- **WebSearch**：精准发现奠基/关键文献并反查 DOI（Deiseroth 2008、Asano 2018 等通过专利/PubMed/OSTI 二次源确认）。
- **检索式类型**：`query=`（模糊）、`query.bibliographic=`（题录）、`query.title=`（题名）。
- 未使用 WoS/Scopus/arXiv/ScienceDirect/CNKI 官方接口（本环境无对应凭证/直连被拦截），但以 Crossref（覆盖这些库元数据）为主通道，等价覆盖；CNKI 中文文献因无可用核验凭证，未纳入主体，仅在背景段以通用知识陈述并标注【证据缺口】。

## 2. 检索关键词（英文正向）
```
S1 硫化物: argyrodite solid electrolyte; Li6PS5X; Li6PS5Cl polymorph; Li10GeP2S12 metastable;
           beta-Li3PS4; alpha-Li3PS4 metastable; thiophosphate; superionic sulfide
S2 卤化物: halide solid electrolyte chloride; Li3YCl6; Li3InCl6; Li2ZrCl6; Li3ErCl6;
           metastable chloride; polymorph halide
S3 氧化物: anti-perovskite Li3OCl; Li3OCl superionic; metastable garnet LLZO
M 机制:   mechanochemical synthesis; non-equilibrium synthesis; order-disorder transition superionic;
           phase transition solid electrolyte; polymorph solid electrolyte
```
- **负向过滤（提前剔除纯非晶）**：标题仅命中 `amorphous / glass / glassy` 且无 `metastable / crystalline / polymorph` 叠加者，降为 C 类"非晶对照"或剔除；非晶文献单列，不计入亚稳相核心池（如 Li7P3S11 玻璃陶瓷、结晶 LiPON 对照）。

## 3. 筛选逻辑（nature-literature-pipeline 六维打分）
- 维度与权重：主题契合 35 / 方法价值 20 / 期刊质量 15 / 研究网络 10 / 应用价值 10 / 存档价值 10。
- 门槛：主题契合 <10 直接淘汰（本池无触发）。总分=六维之和，人工复核无虚高。
- **去重**：以 DOI 为主键，三重提示（DOI / 题名归一化 / arXiv-ID）去重；`.s001/.s002/.v1-.v3` 等补遗/预印本版本后缀剔除，仅保留主版本或明确标注预印本（chemrxiv.12349703）。
- **准入门槛（防幻觉）**：仅收录带可 Crossref 核验有效 DOI 或正式 ChemRxiv DOI 的文献；元数据（作者/年/刊/卷/页）以 Crossref 返回为准。

## 5. 开放获取（OA）与证据分级
- **OA 全文可锚定核心数据**：S1-1（Nat Commun 2026，α-Li3PS4 TTT/快淬/纳米稳）、S3-3（Mater Adv 2022，Li3OCl 室温亚稳/退火分解）、M1（Nat Commun 2019，有序-无序相变原位 EM）。
- **非 OA（仅背景/引文）**：C1–C3、S2-1、S1-7 等顶刊；其定量值（如 LGPS 12 mS/cm、argyrodite ~1–3 mS/cm、Li3YCl6 ~0.5–1 mS/cm）作为领域共识背景引用，亚稳特性专项结论优先绑定 OA 原文。
- 凡核心性能数据（电导率/活化能/相变温度）与机理结论，均标注来源与（OA 时）页码/段落；无法锚定者标【证据缺口】。
