## S3-1 | 富锂反钙钛矿超离子导电奠基 (2012)
- frontmatter: doi 10.1021/ja305709z; J Am Chem Soc 134, 15042–15047(?) ; cls A_核心主线
- 核心主张：富锂反钙钛矿 Li₃OCl 等具三维 Li⁺ 迁移通道，是潜在超离子导体。**学界共识**
- 方法：固相反应。
- 关键发现：开启反钙钛矿固态电解质方向；但其室温热力学不稳定、潮解严重成为后续瓶颈。【证据缺口：原文订阅制，σ 具体数值未全文核验；以社群公认报道范围 10⁻⁷–10⁻⁴ S cm⁻¹（样品/组分依赖）作背景，并标注离散大。】
- 关联：S3 氧化物主体；第 2 章反钙钛矿制备、第 3 章动力学锁相（界面/应变稳定）。

## S3-2 | 富锂反钙钛矿 Li₃OX 反应机理与热力学不稳定 (2016)
- frontmatter: doi 10.1016/j.ssi.2015.11.027; Solid State Ionics 289, 10–(?) ; cls A_核心主线
- 核心主张：纯相 Li₃OCl/Li₃OBr 制备困难，主因是低产率、杂质相、热力学不稳定与潮解。**学界共识**
- 方法：多路线固相反应 + IR/TG-DSC/DFT。
- 关键发现：揭示 Li₃OCl 热力学不稳定本质（易转为 Li₂OHCl 等稳定相）——对应大纲"常压室温热力学非基态"判定；提出 LiH 还原剂、Li₂O+LiX 扩散法改善纯相。【证据缺口：具体相变/分解温度未全文核验。】
- 关联：第 3 章"亚稳相定义"与"动力学锁相"反例（热力学失稳需外力稳定）。

## S3-3 | RF 溅射稳定微量 Li₃OCl 反钙钛矿薄膜 (2022, OA)
- frontmatter: doi 10.1039/d2ma00971d; Mater Adv 3, 8995–9008; OA(RSC); cls A_核心主线
- 核心主张：Li₃OCl 在室温热力学不稳定且极易潮解，但可在薄膜中以少量亚稳反钙钛矿相存在。**成熟共识（摘要级 OA 证据）**
- 方法：Li₂O + LiCl 粉末靶，RF 磁控溅射（~0.5–1 μm 薄膜），全程控湿。
- 关键发现（锚点：Abstract / 正文，来自 OA 原文摘要已抓）：
  - Li₃OCl 室温水热/热力学不稳定，且极易形成结构相似、热力学稳定的羟基卤化物 Li₂OHCl（杂质相风险高）。
  - 以 Li₂O+LiCl 靶溅射，薄膜中稳定出少量与立方 Li₃OCl 预期晶格参数一致的亚稳反钙钛矿相；FT-IR 证实无 O–H 键→确为 Li₃OCl 而非 Li₂OHCl。
  - 该反钙钛矿相在中等温度退火时**分解为 Li₂O + LiCl**（退火失稳→印证亚稳）。
  - Li⁺ 电导率量级约 **10⁻⁸ S cm⁻¹**（低相纯度导致）；Li₂OHCl 经优化有望提升。
  - 这是首次用 RF 溅射合成富锂反钙钛矿的尝试。
- 批判：相纯度低、σ 仅 10⁻⁸ 量级；作为电解质尚远不及硫化物/卤化物，但示范"外延/界面限域（薄膜）"可短期稳定亚稳相。
- 关联：第 2 章氧化物制备（薄膜外延/限域）、第 3 章动力学锁相（界面应变/限域）、第 4 章"高导-失稳"矛盾的典型反面（稳定难→导电低）。

## S3-6 | LLZO 四方→立方相变与电导提升 (2013)
- frontmatter: doi 10.1016/j.ssi.2013.09.029; Solid State Ionics 255, 27–(?) ; cls A_核心主线
- 核心主张：Li₇La₃Zr₂O₁₂ 四方相经掺杂/处理转为立方相，电导显著提升。**学界共识**
- 方法：固相 + 掺杂（Al/Ta 等）。
- 关键发现：立方 LLZO 是亚稳高导相（四方为低温稳定相），需掺杂/快冷维持——对应大纲"亚稳石榴石"与"动力学锁相（快冷）"。社群公认立方 LLZO σ~10⁻⁴–10⁻³ S cm⁻¹、Ea~0.3 eV（背景引用）。【证据缺口：具体相变温度/σ 未全文核验。】
- 关联：第 2 章氧化物制备（掺杂+快冷）、第 3 章动力学锁相、第 4 章对比。
