## 2. 综合：接近完美的计划（内容骨架）

### 2.1 三阶段 × 素材映射

| 阶段 | 时间占比 | 核心任务 | 素材来源 |
|------|---------|---------|---------|
| **基础夯实期** | 前 ~60% | 词汇积累 + 语法/长难句 + 听力输入 | 网盘瑞斯拜·预备课/词汇讲义；MyEnglishNotes 4500词+高频700词+语法；YDdict 四级词库(3739词) |
| **专项突破期** | 中 ~30% | 阅读/听力/翻译/写作 分项突破 | 网盘瑞斯拜·阅读/听力/翻译/写作讲义；CET46-Resources 真题专项；CET-Prompt-Hub 写译模板 |
| **模考冲刺期** | 后 ~10–15% | 历年真题套卷模考 + 查漏 | CET46-Resources 历年真题（55考次）；cet4-spark 星火模拟+音频 |

### 2.2 任务类型（对齐瑞斯拜体系）

规划引擎调度的"任务类型" = 词汇 / 听力 / 阅读 / 写作 / 翻译 / 模考。
这与瑞斯拜资料结构一一对齐，说明计划的内容骨架可落地。

### 2.3 每日任务生成规则

- 输入：考试日期（倒推总天数）、每天可用时长、当前水平、目标分数
- 按"每天可用时长"切块（每块 15–20min），例如 1 小时 → 背词20个 + 听力精听1篇 + 阅读1篇 + 作文模板1篇
- 轻量自适应：某天未完成 → 顺延次日；越近考试 → 模考密度自动加
- 默认参数（用户可改）：水平从基础起步；目标先稳过425；固定三段模板+顺延

### 2.4 进度与打卡

- 首页"今日任务" + 完成勾选 + 进度环
- 规划总览页（按周/阶段看）
