## Spec

### (a) spec 有要求、代码缺失或不完整

1. **M1 关键节点条**：spec 要求"报名/口试/准考证/考试 四个锚点，临近变红+提示"。实为一行文本且只提准考证，报名截止、口试 11-21 全无；"过期显示'已结束'"也未实现（cd<0 返回空串）。`pages/today/today.js:126-133`
2. **M5 应用内待复习区**：spec"今日任务里单列'待复习'区，打开即见"。今日页只有单一任务列表，无分区。`pages/today/today.wxml:94`
3. **复习间隔**：spec"默认 1/2/4/7/15 天"。只生成 +2 天单个节点，且仅对 vocab 类型生效。`utils/engine.js:214-218`
4. **数据模型**：spec §5 的 `checkins`、`reviewNodes` 两个集合不存在；status "2 跳过"未实现。`utils/store.js:4-9`

### (b) 范围蔓延（spec 未要求）

1. **`utils/plan108.js`（342 行）内置逐日精确计划**，含页码/课次。spec §9 明确这些"**不进 App**"，导入包应为用户导入项。
2. **contentRef 硬编码第三方资源**并配"一键绑定"入口：华研八合一/烤鸭TV/瑞斯拜/邹老师翻译。spec §6 要求"contentRef = '' // 留空"。`utils/engine.js:135,150`；`pages/mine/mine.js:194-230`
3. **动效库** `utils/anim.js` + `styles/interactions.wxss`（水波/爆散/翻面/骨架/数字滚动）。spec 只要求"学术质感视觉"。

### (c) 看似实现、实则有误

1. **向导参数不影响排期**：spec §6"N = floor(dailyMinutes/18)"。`generatePlan` 只读 `profile.examDate`，dailyMin/weeklyHours/level/target 全部未参与，任务量由硬编码 `weekHours()` 决定。`utils/engine.js:44-53,69`
2. **阶段切分错误**：spec"专项=[模考.start-11d]"（约 11 天），代码取 -18 天，专项期 18 天、基础期被截短。`utils/engine.js:29`
3. **改考试日不重排**：spec"阶段边界由 examDate 动态算，改考试日自动重排"。但 10.08–12.11 强制走 plan108 硬编码表，改考试日后该段仍是 12-12 的模考排期。`utils/engine.js:73,123`
4. **提醒语义偏了**：云函数推"今日待办数"，非 spec 要求扫 reviewNodes 的 dueDate；且云端是单文档快照 `cet4_sync`，非 spec §5 五集合，`CLOUD_ENV_ID` 默认为空即无云。`cloudfunctions/checkReminders/index.js:35-39`
